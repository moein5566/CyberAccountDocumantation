# بروز رسانی _ `روش دستی`

برای `بروز رسانی نرم افزار` به `روش دستی` طبق مراحل زیر پیش بروید:

1. اگر برنامه باز است، ابتدا آن را ببندید.
2. بر روی آیکن نرم افزار کلیک راست کرده و `open file location` را انتخاب کنید.
3. بر روی عبارت **Extract to** کلیک کرده و محتویات فایل را در فولدری به همین نام استخراج کنید.
4. وارد پوشه ی ایجاد شده شوید و سپس وارد پوشه ی **prog** شوید.
5. تمامی محتویات این پوشه را کپی کرده و سپس در `محل نصب نرم افزار` آنها را قرار دهید.
6. هنگامی که با پیغام فایل ها با نام مشابه وجود دارد مواجه شدید، گزینه ی **Replace** را انتخاب کنید.

برای تکمیل فرایند `بروز رسانی` پس از انجام مراحل فوق وارد نرم افزار شوید.
