# نصب SQL Server

## هدف
این راهنما برای نصب `SQL Server` جهت استفاده از نرم‌افزار `حسابگر` استفاده می‌شود.

---

## دریافت فایل نصب

- روی `سی‌دی نرم‌افزار`، مسیر `ADDIN` شامل فایل‌های نصبی `SQL Server` است.
- نسخه‌های پشتیبانی‌شده: `SQL Server 2008` تا `2019`.
- نسخه‌های پیش‌فرض روی سی‌دی: `2008` و `2014`.
- برای دریافت نسخه‌های دیگر یا فایل آموزشی کامل، در **پرتال مشتریان** سایت شایگان سیستم (`https://clients.shygunsys.net`) یک تیکت ثبت کن.

---

## نکات کلیدی

- نسخه `SQL Server` را بر اساس سخت‌افزار و ویندوز خود انتخاب کن.
- راهنمای کامل نصب گام‌به‌گام در فایل جداگانه موجود است (در صورت نیاز، تیکت بزن).
