# خطای "در حال ایجاد شرکت ماندن"

## هدف
این راهنما برای رفع مشکل گیر کردن نرم‌افزار `حسابگر` در حالت `در حال ایجاد شرکت` استفاده می‌شود.

---

## مراحل عیب‌یابی

### ۱. بررسی نصب بودن SQL Server
- `This PC > Manage > Services and Applications` را باز کن.
- باید پوشه `SQL Server Configuration Manager` در این مسیر قابل مشاهده باشد.
- اگر موجود نیست، یعنی `SQL Server` نصب نشده است.
- برای دریافت راهنمایی نصب، برای `پشتیبانی شرکت شایگان سیستم` تیکت بفرست.

### ۲. بررسی محل نصب (مسیر) در زمان ایجاد شرکت
اگر `SQL Server` نصب است و مشکل همچنان وجود دارد، در زمان ایجاد شرکت، موارد زیر را بررسی کن:

- **نام خلاصه**: نباید تکراری باشد.
- **محل نصب**: باید به صورت `PC Name\SQL Instance Name` وارد شود.
  - مثال: اگر نام کامپیوتر `PC` و نام `Instance` پایگاه داده `SHYGUN2014` باشد، مسیر باید `PC\SHYGUN2014` باشد.
