# عیب‌یابی: برنامه در حالت "در حال باز کردن شرکت" می‌ماند

## هدف
این راهنما برای رفع مشکل توقف برنامه `حسابگر` در مرحله‌ی `در حال باز کردن شرکت` پس از انتخاب شرکت، ناشی از عدم ارتباط با `SQL Server` است.

## مراحل عیب‌یابی (به ترتیب)

### ۱. بررسی فعال بودن سرویس `SQL Server` (در سرور)
- نام `Instance` را از ستون `سرور` در منوی انتخاب شرکت (قبل از `\`) یادداشت کن.
- در سرور: `This PC > Manage > Services and Applications > Services`.
- سرویس `SQL Server (Instance Name)` را پیدا کن.
- اگر وضعیت `Stopped` است: روی `Start` کلیک کن.
- اگر وضعیت `Running` است: روی `Restart` کلیک کن.
- اگر خطا داد: با `پشتیبانی شرکت شایگان سیستم` تماس بگیر.

### ۲. بررسی نام/آدرس `IP` سرور
- نام یا `IP` سرور باید با مقدار قبل از `\` در ستون `سرور` یکی باشد.
- برای بررسی نام: `This PC > Properties > Device Name`.
- برای بررسی `IP`: در سرور، `cmd > ipconfig` و مقدار `IPv4 Address` را ببین.
- اگر متفاوت بود: در منوی انتخاب شرکت، روی `اصلاح` کلیک کن و مقدار قبل از `\` را با نام یا `IP` جدید جایگزین کن و `ذخیره` کن.

### ۳. خاموش کردن `Firewall` (سرور و کلاینت‌ها)
- `Control Panel > Windows Defender Firewall > Turn Windows Defender Firewall on or off`.
- گزینه‌ی `Turn off Windows Defender Firewall (not recommended)` را برای هر دو بخش (خصوصی و عمومی) فعال کن.
- **توجه**: برای حفظ امنیت، به‌جای خاموش‌سازی، پورت‌های جدول پیوست را باز کن.

### ۴. فعال کردن `TCP/IP` در `SQL Server` (سرور)
- `This PC > Manage > Services and Applications > SQL Server Configuration Manager`.
- مسیر: `SQL Server Network Configuration > Protocols for <InstanceName>`.
- روی `TCP/IP` راست‌کلیک و اگر `Disabled` است، `Enable` را بزن.
- سپس در همان پنجره، از چپ `SQL Server Services` را انتخاب کن.
- روی `SQL Server (InstanceName)` راست‌کلیک و `Restart` کن.

## پیوست: پورت‌های موردنیاز برای باز کردن در `Firewall`

| Protocol | Ports                 | Service / Program |
| -------- | --------------------- | ----------------- |
| TCP      | 1433, 135, 2383, 4022 | `SQL Server`      |
| UDP      | 1434                  | `SQL Server`      |
| TCP      | 6001                  | `Sentinel`        |
| TCP      | 5680                  | `Unikey`          |
| TCP      | 3389                  | `Remote Desktop`  |
| TCP      | 1010                  | `Sync Service`    |
| TCP      | 2030                  | `Web Service`     |

> تمام پورت‌ها باید به‌صورت `inbound` و `outbound` تنظیم شوند.
