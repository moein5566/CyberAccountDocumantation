# قسمت‌های موجود در فرم فاکتور فروش

در این مقاله به بررسی دکمه‌ها و امکانات موجود در فرم **فاکتور فروش** نرم‌افزار `حسابگر` می‌پردازیم.

---

## دکمه‌های اصلی فرم فاکتور فروش

|  ردیف |        عنوان |                                                        توضیح |
| ----: | -----------: | -----------------------------------------------------------: |
| **۱** |   **`خروج`** |             با زدن روی این قسمت، فرم فاکتور فروش بسته می‌شود. |
| **۲** | **`انصراف`** | اگر مایل به انصراف از عمل اخیر انجام شده باشید، گزینه **`انصراف`** را بزنید. |
| **۳** |  **`ذخیره`** | اگر بخواهید تغییرات اعمال شده را ذخیره کنید، بر روی گزینه **`ذخیره`** کلیک کنید. |
| **۴** |  **`اصلاح`** | اگر گزینه **`اصلاح`** را بزنید، می‌توانید فاکتور خود را اصلاح کنید. |
| **۵** |   **`جدید`** | اگر بخواهید فاکتور جدیدی را ایجاد کنید، بر روی گزینه **`جدید`** کلیک کنید. |
| **۶** |    **`چاپ`** | اگر بخواهید از فاکتور مد نظر چاپ بگیرید، بر روی گزینه **`چاپ`** کلیک کنید. |

## امکانات مربوط به سند و گزارش‌گیری

|   ردیف |         عنوان |                                                        توضیح |
| -----: | ------------: | -----------------------------------------------------------: |
|  **۷** |     **`ثبت`** | اگر بخواهید سند فاکتور انتخاب شده ثبت شود، بر روی گزینه **`ثبت`** کلیک کنید. |
|  **۸** |  **`کاردکس`** | اگر بخواهید کاردکس کالای موجود در فاکتور را مشاهده کنید، روی کالا کلیک کرده و گزینه **`کاردکس`** را بزنید. |
|  **۹** |    **`گردش`** | اگر بخواهید گردش حساب مشتری موجود در فاکتور را ببینید، نام یا کد مشتری را انتخاب کنید و بر روی گزینه **`گردش`** کلیک کنید. |
| **۱۰** | **`تغییرات`** | اگر بخواهید تغییرات اعمال شده توسط کاربران را مشاهده کنید، بر روی گزینه **`تغییرات`** کلیک کنید. |

## امکانات تکمیلی فرم فاکتور

|   ردیف |                   عنوان |                                                        توضیح |
| -----: | ----------------------: | -----------------------------------------------------------: |
| **۱۱** |             **`ارسال`** | اگر اقلام فاکتور فروش شما توسط خودروهای پخش به مشتری تحویل داده شود، برای ثبت اطلاعات راننده و خودرو بر روی گزینه **`ارسال`** کلیک کنید. |
| **۱۲** |        **`نمایش کلید`** | اگر بخواهید کنار فاکتور، پنل اعداد نمایش داده شود، بر روی گزینه **`نمایش کلید`** کلیک کنید. |
| **۱۳** |             **`پیوست`** | اگر بخواهید پیوست این فاکتور را در دیتابیس ذخیره کنید، بر روی **`پیوست`** کلیک کنید، دکمه **`جدید`** را بزنید، فایل خود را انتخاب کرده و تایید کنید. |
| **۱۴** |   **`تبدیل از فاکتور`** | اگر بخواهید یک حواله انبار مقداری خود را به فاکتور فروش تبدیل کنید، بر روی این گزینه کلیک کنید، سپس در لیست باز شده، حواله انبار مقداری مد نظر را انتخاب کرده و تایید کنید. |
| **۱۵** |          **`سبد کالا`** | اگر بخواهید قوانین سبد کالا بر روی یک یا چند ردیف فاکتور اعمال یا مشاهده شود، بر روی قسمت **`سبد کالا`** کلیک کنید. |
| **۱۶** |     **`ابطال/درجریان`** | اگر بخواهید فاکتور جاری را به ابطال شده و برعکس تبدیل کنید، بر روی قسمت **`ابطال/درجریان`** کلیک کنید. |
| **۱۷** |     **`سامانه مودیان`** | با کلیک بر روی این گزینه، می‌توانید اعمال مربوط به سامانه مودیان این فاکتور را انجام دهید. |
| **۱۸** | **`سامانه جامع تجارت`** | با کلیک بر روی این گزینه، می‌توانید اعمال مربوط به سامانه جامع تجارت این فاکتور را انجام دهید. |
| **۱۹** |            **`راهنما`** | راهنمای استفاده از قسمت فاکتور فروش می‌باشد. با کلیک بر روی آن، توضیحات لازم در مورد نحوه کارکرد قسمت‌های مختلف ارائه شده است. |

## امکانات مربوط به مدیریت کالا و حساب

|   ردیف |               عنوان |                                                        توضیح |
| -----: | ------------------: | -----------------------------------------------------------: |
| **۲۰** |          **`حساب`** | اگر هنگام ورود فاکتور بخواهید نام حساب مشتری جدیدی وارد نرم‌افزار کنید، بر روی قسمت **`حساب`** کلیک کرده و حساب مد نظر را تعریف کنید. |
| **۲۱** | **`دریافتی لیستی`** | اگر بخواهید برای این فاکتور برگه دریافت لیستی تعریف کنید، بر روی گزینه **`دریافتی لیستی`** کلیک کنید. |
| **۲۲** |          **`کالا`** | اگر هنگام ورود فاکتور بخواهید نام کالای جدیدی وارد نرم‌افزار کنید، بر روی قسمت **`کالا`** کلیک کرده و کالای مد نظر را تعریف کنید. |
| **۲۳** |     **`وضع تخفیف`** | اگر بخواهید به یک ردیف کالای فاکتور بیش از یک درصد تخفیف ردیف اعمال کنید، از قسمت **`وضع تخفیف`** استفاده کنید. |
| **۲۴** |   **`به ترتیب کد`** |   کالاهای موجود در فاکتور فروش به ترتیب کد کالا مرتب می‌شوند. |
| **۲۵** |  **`به ترتیب نام`** |  کالاهای موجود در فاکتور فروش به ترتیب نام کالا مرتب می‌شوند. |
| **۲۶** |         **`سریال`** |             در این قسمت، سریال ردیف کالاها نمایش داده می‌شود. |

## امکانات مالی و تسویه

|   ردیف |              عنوان |                                                        توضیح |
| -----: | -----------------: | -----------------------------------------------------------: |
| **۲۷** |   **`برگ دریافت`** | اگر بخواهید به این فاکتور برگ دریافت مرتبط کنید، از این گزینه استفاده کنید. |
| **۲۸** |     **`دفتر قسط`** | اگر بخواهید مبلغ این فاکتور را برای مشتری قسط‌بندی کنید، از این گزینه استفاده کنید. |
| **۲۹** |        **`تسویه`** | اگر مشتری مبلغ فاکتور را تسویه کند، برای صدور سند تسویه در سیستم بر روی گزینه **`تسویه`** کلیک کنید. |
| **۳۰** | **`ارسال (ردیف)`** | اگر بخواهید تنها بر روی یک یا چند ردیف ارسال فاکتور صورت گیرد، از این گزینه استفاده کنید. برای این کار، بر روی ردیف مد نظر کلیک کنید و گزینه **`ارسال`** را بزنید. |
| **۳۱** |     **`پرداختها`** | اگر بخواهید وضعیت پرداختی‌های ثبت شده برای این فاکتور را مشاهده کنید، بر روی گزینه **`پرداختها`** کلیک کنید. |

## امکانات جانبی و پیشرفته

|   ردیف |             عنوان |                                                        توضیح |
| -----: | ----------------: | -----------------------------------------------------------: |
| **۳۲** |      **`باسکول`** | برای ارتباط ترازو با فاکتور از این گزینه استفاده کنید. اگر ترازو به سیستم شما متصل باشد، وزن کالای روی باسکول در قسمت مقدار فاکتور فروش اضافه خواهد شد. |
| **۳۳** | **`سریال تجمعی`** | اگر بخواهید به ردیف کالاها سریال بدهید ولی شماره این سریال‌ها هیچ اهمیتی برای شما نداشته باشد، می‌توانید از سریال تجمیعی استفاده کنید. به این ترتیب که شما محدوده سریال را وارد می‌کنید و سیستم به دلخواه به ردیف کالاها سریال مربوطه را اختصاص می‌دهد. |
| **۳۴** |   **`وضع هزینه`** | در این قسمت، هزینه‌های سرشکن شده روی کالاها را مشاهده می‌کنید. |
| **۳۵** |  **`ارسال پیام`** | اگر بخواهید هنگام صدور فاکتور برای مشتری، پیامک ارسال شود، از گزینه **`ارسال پیام`** استفاده کنید. |
| **۳۶** | **`دریافت سریع`** | اگر دستگاه پوز به نرم‌افزار متصل باشد، برای دریافت پول از مشتری می‌توانید نوع پرداخت از طریق کارتخوان را انتخاب کنید. مبلغ بر روی دستگاه کارتخوان نمایش داده می‌شود و سپس مبلغ را از طریق کارتخوان تسویه کنید. همچنین می‌توانید نوع پرداخت‌های دیگر و کارتخوان‌های دیگر را نیز اضافه کنید. |
| **۳۷** |    **`مرتبط به`** | اگر این فاکتور از حواله مقداری کپی شده باشد، لیست فاکتور مرتبط را مشاهده کنید. |
| **۳۸** |    **`سری ساخت`** | اگر بخواهید برای ردیف کالای فاکتور سری ساخت تعریف و اختصاص دهید، بر روی گزینه **`سری ساخت`** کلیک کنید. |
| **۳۹** |  **`هزینه ردیف`** | اگر بخواهید برای ردیف فاکتور هزینه ردیف (ارزش افزوده ردیفی) تعریف کنید، بر روی این گزینه کلیک کنید. |
| **۴۰** |   **`چاپ بارکد`** | اگر بخواهید بارکدهای ردیف کالا را چاپ بگیرید، بر روی این گزینه کلیک کنید. |
