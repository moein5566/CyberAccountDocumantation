# پورت‌های مورد استفاده در برنامه حسابگر

در این مقاله، پورت‌های مورد نیاز برای استفاده از سرویس‌های مختلف نرم‌افزار `حسابگر` و شرکت شایگان سیستم معرفی می‌شوند.

---

## جدول پورت‌ها

|  پروتکل   |                     پورت                      |      نام برنامه      |
| :-------: | :-------------------------------------------: | :------------------: |
| **`TCP`** | **`1433`**، **`135`**، **`2383`**، **`4022`** |      **`SQL`**       |
| **`UDP`** |                  **`1434`**                   |                      |
| **`TCP`** |                  **`6001`**                   |    **`Sentinel`**    |
| **`TCP`** |                  **`5680`**                   |     **`Unikey`**     |
| **`TCP`** |                  **`3389`**                   | **`Remote Desktop`** |
| **`TCP`** |                  **`1010`**                   |  **`Sync Service`**  |
| **`TCP`** |                  **`2030`**                   |  **`Web Service`**   |

---

## نکات مهم

- پورت‌های ذکر شده در جدول بالا، برای استفاده از سرویس‌های مختلف شرکت شایگان سیستم لازم است **باز** باشند.
- جهت حفظ **حداکثری امنیت شبکه** خود، با متخصص شبکه در این خصوص مشورت کنید.
- تمام پورت‌های ذکر شده **قابل تغییر** هستند، اما به علت حساسیت بالا، حتماً با یک **کارشناس شبکه** مشورت کنید.
- تمام پورت‌ها باید به صورت **`Inbound`** و **`Outbound`** تنظیم شوند.
