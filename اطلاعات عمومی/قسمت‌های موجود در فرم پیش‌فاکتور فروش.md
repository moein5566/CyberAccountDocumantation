# قسمت‌های موجود در فرم پیش‌فاکتور فروش

در این مقاله به بررسی دکمه‌ها و امکانات موجود در فرم **پیش‌فاکتور فروش** نرم‌افزار `حسابگر` می‌پردازیم.

---

## دکمه‌های اصلی فرم پیش‌فاکتور

|  ردیف |        عنوان |                                                        توضیح |
| ----: | -----------: | -----------------------------------------------------------: |
| **۱** |   **`خروج`** |          با زدن روی این قسمت، فرم پیش‌فاکتور فروش بسته می‌شود. |
| **۲** | **`انصراف`** | اگر مایل به انصراف از عمل اخیر انجام شده باشید، گزینه **`انصراف`** را بزنید. |
| **۳** |  **`ذخیره`** | اگر بخواهید تغییرات اعمال شده را ذخیره کنید، بر روی گزینه **`ذخیره`** کلیک کنید. |
| **۴** |  **`اصلاح`** | اگر گزینه **`اصلاح`** را بزنید، می‌توانید پیش‌فاکتور خود را اصلاح کنید. |
| **۵** |   **`جدید`** | اگر بخواهید پیش‌فاکتور جدیدی ایجاد کنید، بر روی گزینه **`جدید`** کلیک کنید. |
| **۶** |    **`چاپ`** | اگر بخواهید از پیش‌فاکتور مد نظر چاپ بگیرید، بر روی گزینه **`چاپ`** کلیک کنید. |

---

## امکانات تکمیلی و گزارش‌گیری

|   ردیف |                    عنوان |                                                        توضیح |
| -----: | -----------------------: | -----------------------------------------------------------: |
|  **۷** |             **`کاردکس`** | اگر بخواهید کاردکس کالای موجود در پیش‌فاکتور را مشاهده کنید، روی کالا کلیک کرده و گزینه **`کاردکس`** را بزنید. |
|  **۸** |               **`گردش`** | اگر بخواهید گردش حساب مشتری موجود در پیش‌فاکتور را ببینید، نام یا کد مشتری را انتخاب کنید و بر روی گزینه **`گردش`** کلیک کنید. |
|  **۹** |            **`تغییرات`** | اگر بخواهید تغییرات اعمال شده توسط کاربران را مشاهده کنید، بر روی گزینه **`تغییرات`** کلیک کنید. |
| **۱۰** |         **`نمایش کلید`** | اگر بخواهید کنار پیش‌فاکتور، پنل اعداد نمایش داده شود، بر روی گزینه **`نمایش کلید`** کلیک کنید. |
| **۱۱** |              **`پیوست`** | اگر بخواهید پیوست این پیش‌فاکتور را در دیتابیس ذخیره کنید، بر روی **`پیوست`** کلیک کنید، دکمه **`جدید`** را بزنید، فایل خود را انتخاب کرده و تایید کنید. |
| **۱۲** | **`تبدیل از پیش‌فاکتور`** | اگر بخواهید یک حواله انبار مقداری خود را به پیش‌فاکتور فروش تبدیل کنید، بر روی این گزینه کلیک کنید، سپس در لیست باز شده، حواله انبار مقداری مد نظر را انتخاب کرده و تایید کنید. |
| **۱۳** |           **`سبد کالا`** | اگر بخواهید قوانین سبد کالا بر روی یک یا چند ردیف پیش‌فاکتور اعمال یا مشاهده شود، بر روی قسمت **`سبد کالا`** کلیک کنید. |
| **۱۴** |      **`ابطال/درجریان`** | اگر بخواهید پیش‌فاکتور جاری را به ابطال شده و برعکس تبدیل کنید، بر روی قسمت **`ابطال/درجریان`** کلیک کنید. |
| **۱۵** |             **`راهنما`** | راهنمای استفاده از قسمت پیش‌فاکتور فروش می‌باشد. با کلیک بر روی آن، توضیحات لازم در مورد نحوه کارکرد قسمت‌های مختلف ارائه شده است. |

## امکانات مربوط به مدیریت کالا و حساب

|   ردیف |              عنوان |                                                        توضیح |
| -----: | -----------------: | -----------------------------------------------------------: |
| **۱۶** |         **`حساب`** | اگر هنگام ورود پیش‌فاکتور بخواهید نام حساب مشتری جدیدی وارد نرم‌افزار کنید، بر روی قسمت **`حساب`** کلیک کرده و حساب مد نظر را تعریف کنید. |
| **۱۷** |         **`کالا`** | اگر هنگام ورود پیش‌فاکتور بخواهید نام کالای جدیدی وارد نرم‌افزار کنید، بر روی قسمت **`کالا`** کلیک کرده و کالای مد نظر را تعریف کنید. |
| **۱۸** |    **`وضع تخفیف`** | اگر بخواهید به یک ردیف کالای پیش‌فاکتور بیش از یک درصد تخفیف ردیف اعمال کنید، از قسمت **`وضع تخفیف`** استفاده کنید. |
| **۱۹** |  **`به ترتیب کد`** | کالاهای موجود در پیش‌فاکتور فروش به ترتیب کد کالا مرتب می‌شوند. |
| **۲۰** | **`به ترتیب نام`** | کالاهای موجود در پیش‌فاکتور فروش به ترتیب نام کالا مرتب می‌شوند. |

## امکانات مالی و تسویه

|   ردیف |          عنوان |                                                        توضیح |
| -----: | -------------: | -----------------------------------------------------------: |
| **۲۱** | **`دفتر قسط`** | اگر بخواهید مبلغ این پیش‌فاکتور را برای مشتری قسط‌بندی کنید، از این گزینه استفاده کنید. |
| **۲۲** | **`پرداختها`** | اگر بخواهید وضعیت پرداختی‌های ثبت شده برای این پیش‌فاکتور را مشاهده کنید، بر روی گزینه **`پرداختها`** کلیک کنید. |

## امکانات جانبی و پیشرفته

|   ردیف |            عنوان |                                                        توضیح |
| -----: | ---------------: | -----------------------------------------------------------: |
| **۲۳** |     **`باسکول`** | برای ارتباط ترازو با پیش‌فاکتور از این گزینه استفاده کنید. اگر ترازو به سیستم شما متصل باشد، وزن کالای روی باسکول در قسمت مقدار پیش‌فاکتور فروش اضافه خواهد شد. |
| **۲۴** |   **`سری ساخت`** | اگر بخواهید برای ردیف کالای پیش‌فاکتور سری ساخت تعریف و اختصاص دهید، بر روی گزینه **`سری ساخت`** کلیک کنید. |
| **۲۵** | **`هزینه ردیف`** | اگر بخواهید برای ردیف پیش‌فاکتور هزینه ردیف (ارزش افزوده ردیفی) تعریف کنید، بر روی این گزینه کلیک کنید. |
| **۲۶** |  **`چاپ بارکد`** | اگر بخواهید بارکدهای ردیف کالا را چاپ بگیرید، بر روی این گزینه کلیک کنید. |
| **۲۷** |  **`وضع هزینه`** | در این قسمت، هزینه‌های سرشکن شده روی کالاها را مشاهده می‌کنید. |
| **۲۸** | **`ارسال پیام`** | اگر بخواهید هنگام صدور پیش‌فاکتور برای مشتری، پیامک ارسال شود، از گزینه **`ارسال پیام`** استفاده کنید. |
