# تهیه تصویر از صفحه نمایش

گاهی هنگام اجرای نرم‌افزار و یا در هنگام استفاده از بخش‌های مختلف نرم‌افزار `حسابگر` با خطایی مواجه می‌شوید و یا برای پرسش دقیق‌تر سوالات خود از طریق تیکت نیاز است تا تصویر ارسال کنید. در این مقاله به **۳ روش ساده** برای تهیه تصویر از محیط ویندوز و محیط نرم‌افزار حسابگر می‌پردازیم.

---

## روش اول: استفاده از کلیدهای ترکیبی `Windows + PrtScrn`

با استفاده از کلیدهای ترکیبی **`Windows + PrtScrn`** می‌توانید از صفحه ویندوز خود و یا محیط نرم‌افزار حسابگر تصویر تهیه کنید.

برای دسترسی به تصویر ذخیره شده، به ترتیب وارد پوشه‌های زیر شوید:

**`Users`** > **`Pictures`** > **`Screenshots`**

سپس اقدام به ارسال تصویر کنید.

---

## روش دوم: استفاده از کلیدهای ترکیبی `Windows + Shift + S`

با استفاده از کلیدهای ترکیبی **`Windows + Shift + S`**، ابزار تهیه تصویر از صفحه نمایش برای شما باز می‌شود.

### گزینه‌های موجود در ابزار Snip & Sketch

|                  گزینه |                                                        توضیح |
| ---------------------: | -----------------------------------------------------------: |
| **`Rectangular Snip`** | با استفاده از این قابلیت و توسط مکان‌نما، یک مستطیل روی صفحه خود بکشید. |
|    **`Freeform Snip`** | با استفاده از مکان‌نما، یک شکل دلخواه روی صفحه نمایش ترسیم و ذخیره کنید. |
|     **`Windows Snip`** | نشانگر نمایش داده شده را روی یک پنجره (محیط نرم‌افزار و ...) قرار دهید و برای تهیه تصویر کلیک کنید. |
|  **`FullScreen Snip`** | با استفاده از این گزینه، یک اسکرین‌شات از کل صفحه نمایش تهیه کنید. |
|   **`Close Snipping`** | برای خروج از قسمت تنظیمات ابزار `Snip & Sketch`، از این گزینه یا دکمه **`ESC`** روی کیبورد خود استفاده کنید. |

---

## روش سوم: استفاده از ابزار Snipping Tool

۱. وارد منوی **استارت** ویندوز شوید.

۲. عبارت **`Snipping Tool`** را جستجو و اجرا کنید.

۳. هنگامی که ابزار اجرا شد، روی گزینه **`New`** کلیک کنید.

۴. با استفاده از نشانگر ایجاد شده، از خطای نمایش داده شده و یا قسمتی از نرم‌افزار که می‌خواهید در رابطه با آن سوالی مطرح کنید، تصویر تهیه کنید.

۵. تصویر را از طریق تیکت پشتیبانی به بخش مربوطه ارسال کنید.

### امکانات ابزار Snipping Tool

- در بخش **`Mode`**، تمامی گزینه‌ها مشابه ابزار `Snip & Sketch` می‌باشد.

- در بخش **`Delay`**، می‌توانید مشخص کنید تهیه تصویر از صفحه نمایش با چند ثانیه تاخیر انجام شود (بین `۱` تا `۵` ثانیه).

- پس از تهیه تصویر، می‌توانید:
  - با استفاده از ابزار **`Pen`**، متنی در عکس تهیه شده یادداشت کنید.
  - با استفاده از گزینه **`Highlighter`**، بخشی از تصویر را علامت‌گذاری کنید.
  - برای حذف تغییرات، از گزینه **`Eraser`** استفاده کنید.
  - برای تغییرات بیشتر، از گزینه **`Edit with Paint 3D`** استفاده کنید.
