# قسمت‌های موجود در فرم سفارش فروش

در این مقاله به بررسی دکمه‌ها و امکانات موجود در فرم **سفارش فروش** نرم‌افزار `حسابگر` می‌پردازیم.

---

## دکمه‌های اصلی فرم سفارش فروش

|  ردیف |        عنوان |                                                        توضیح |
| ----: | -----------: | -----------------------------------------------------------: |
| **۱** |   **`خروج`** |              با زدن روی این قسمت، فرم سفارش فروش بسته می‌شود. |
| **۲** | **`انصراف`** | اگر مایل به انصراف از عمل اخیر انجام شده باشید، گزینه **`انصراف`** را بزنید. |
| **۳** |  **`ذخیره`** | اگر بخواهید تغییرات اعمال شده را ذخیره کنید، بر روی گزینه **`ذخیره`** کلیک کنید. |
| **۴** |  **`اصلاح`** | اگر گزینه **`اصلاح`** را بزنید، می‌توانید سفارش خود را اصلاح کنید. |
| **۵** |   **`جدید`** | اگر بخواهید سفارش جدیدی را ایجاد کنید، بر روی گزینه **`جدید`** کلیک کنید. |
| **۶** |    **`چاپ`** | اگر بخواهید از سفارش مد نظر چاپ بگیرید، بر روی گزینه **`چاپ`** کلیک کنید. |

## امکانات مربوط به سند و گزارش‌گیری

|   ردیف |         عنوان |                                                        توضیح |
| -----: | ------------: | -----------------------------------------------------------: |
|  **۷** |     **`ثبت`** | اگر بخواهید سند فاکتور خود را ثبت کنید، بر روی گزینه **`ثبت`** کلیک کنید. |
|  **۸** |     **`سند`** | اگر بخواهید سند مرتبط به فاکتور را مشاهده کنید، بر روی گزینه **`سند`** کلیک کنید. |
|  **۹** |  **`کاردکس`** | اگر بخواهید کاردکس کالای موجود در سفارش را مشاهده کنید، روی کالا کلیک کرده و گزینه **`کاردکس`** را بزنید. |
| **۱۰** |    **`گردش`** | اگر بخواهید گردش حساب مشتری موجود در سفارش را ببینید، نام یا کد مشتری را انتخاب کنید و بر روی گزینه **`گردش`** کلیک کنید. |
| **۱۱** | **`تغییرات`** | اگر بخواهید تغییرات اعمال شده توسط کاربران را مشاهده کنید، بر روی گزینه **`تغییرات`** کلیک کنید. |

## امکانات تکمیلی فرم سفارش

|   ردیف |               عنوان |                                                        توضیح |
| -----: | ------------------: | -----------------------------------------------------------: |
| **۱۲** |    **`نمایش کلید`** | اگر بخواهید کنار سفارش، پنل اعداد نمایش داده شود، بر روی گزینه **`نمایش کلید`** کلیک کنید. |
| **۱۳** |         **`پیوست`** | اگر بخواهید پیوست این سفارش را در دیتابیس ذخیره کنید، بر روی **`پیوست`** کلیک کنید، دکمه **`جدید`** را بزنید، فایل خود را انتخاب کرده و تایید کنید. |
| **۱۴** | **`ابطال/درجریان`** | اگر بخواهید سفارش جاری را به ابطال شده و برعکس تبدیل کنید، بر روی قسمت **`ابطال/درجریان`** کلیک کنید. |
| **۱۵** |        **`راهنما`** | راهنمای استفاده از قسمت سفارش فروش می‌باشد. با کلیک بر روی آن، توضیحات لازم در مورد نحوه کارکرد قسمت‌های مختلف ارائه شده است. |

---

## امکانات مربوط به مدیریت کالا و حساب

|   ردیف |              عنوان |                                                        توضیح |
| -----: | -----------------: | -----------------------------------------------------------: |
| **۱۶** |         **`حساب`** | اگر هنگام ورود سفارش بخواهید نام حساب مشتری جدیدی وارد نرم‌افزار کنید، بر روی قسمت **`حساب`** کلیک کرده و حساب مد نظر را تعریف کنید. |
| **۱۷** |         **`کالا`** | اگر هنگام ورود سفارش بخواهید نام کالای جدیدی وارد نرم‌افزار کنید، بر روی قسمت **`کالا`** کلیک کرده و کالای مد نظر را تعریف کنید. |
| **۱۸** |    **`وضع تخفیف`** | اگر بخواهید به یک ردیف کالای سفارش بیش از یک درصد تخفیف ردیف اعمال کنید، از قسمت **`وضع تخفیف`** استفاده کنید. |
| **۱۹** |  **`به ترتیب کد`** |    کالاهای موجود در سفارش فروش به ترتیب کد کالا مرتب می‌شوند. |
| **۲۰** | **`به ترتیب نام`** |   کالاهای موجود در سفارش فروش به ترتیب نام کالا مرتب می‌شوند. |

## امکانات جانبی و پیشرفته

|   ردیف |            عنوان |                                                        توضیح |
| -----: | ---------------: | -----------------------------------------------------------: |
| **۲۲** |     **`باسکول`** | برای ارتباط ترازو با سفارش از این گزینه استفاده کنید. اگر ترازو به سیستم شما متصل باشد، وزن کالای روی باسکول در قسمت مقدار سفارش فروش اضافه خواهد شد. |
| **۲۳** |   **`سری ساخت`** | اگر بخواهید برای ردیف کالای سفارش سری ساخت تعریف و اختصاص دهید، بر روی گزینه **`سری ساخت`** کلیک کنید. |
| **۲۴** | **`هزینه ردیف`** | اگر بخواهید برای ردیف سفارش هزینه ردیف (ارزش افزوده ردیفی) تعریف کنید، بر روی این گزینه کلیک کنید. |
| **۲۵** |  **`چاپ بارکد`** | اگر بخواهید بارکدهای ردیف کالا را چاپ بگیرید، بر روی این گزینه کلیک کنید. |
| **۲۶** |  **`وضع هزینه`** | در این قسمت، هزینه‌های سرشکن شده روی کالاها را مشاهده می‌کنید. |
| **۲۷** | **`ارسال پیام`** | اگر بخواهید هنگام صدور سفارش برای مشتری، پیامک ارسال شود، از گزینه **`ارسال پیام`** استفاده کنید. |
