# لیست دستگاه‌های POS متصل به برنامه حسابگر

در این مقاله، لیست دستگاه‌های کارتخوان (`POS`) که قابلیت اتصال به نرم‌افزار `حسابگر` را دارند، به همراه مدل و نحوه اتصال هر یک ارائه می‌شود.

---

## لیست دستگاه‌های POS

|        نام دستگاه |  مدل دستگاه |                      نحوه اتصال |
| ----------------: | ----------: | ------------------------------: |
|     **ایران کیش** |   `PaxS800` |             اتصال از طریق `COM` |
| **به پرداخت ملت** |  `Verifone` |              اتصال از طریق شبکه |
|     **مبنا کارت** |    `Ict220` |      اتصال از طریق `COM` و شبکه |
|          **فن‌آب** | `V3` و `V5` |        اتصال از طریق پورت `COM` |
|    **سداد (ملی)** | `Blue bird` |              اتصال از طریق شبکه |
|         **سامان** |    `PaxS80` |              اتصال از طریق شبکه |
|   **آسان پرداخت** |  `Verifone` |              اتصال از طریق شبکه |
|         **فن‌آوا** | `VEGA5000s` | اتصال از طریق شبکه و پورت `COM` |

---

## مراحل راه‌اندازی دستگاه POS

برای راه‌اندازی سیستم، مراحل زیر را به ترتیب انجام دهید:

| مرحله |                                                        توضیح |
| ----: | -----------------------------------------------------------: |
| **۱** | کاربر باید دستگاه `POS` را به حالت `POS` (با نحوه اتصال ذکر شده در جدول فوق) تبدیل کند. |
| **۲** | از طریق برنامه‌های واسط شرکت ارائه‌دهنده دستگاه `POS`، اتصال دستگاه با رایانه برقرار باشد. |
| **۳** | سپس توسط کارشناسان شرکت شایگان سیستم، تنظیمات داخل برنامه `حسابگر` انجام می‌شود. |

---

## پیش‌نیازهای استفاده از این امکان

|           پیش‌نیاز |                                                 توضیح |
| ----------------: | ----------------------------------------------------: |
| **نسخه نرم‌افزار** | کاربر باید حداقل نسخه **`۹`** `حسابگر` را داشته باشد. |
|     **Framework** |    حداقل باید **`Framework 4.7`** روی سیستم نصب باشد. |

## نکته

این دانشنامه بر اساس **آخرین تغییرات برنامه `حسابگر`** تهیه شده است. در صورت بروز تغییرات در نسخه‌های جدید، اطلاعات ممکن است به‌روزرسانی شود.
