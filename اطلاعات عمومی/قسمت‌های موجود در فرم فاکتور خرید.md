# قسمت‌های موجود در فرم فاکتور خرید

در این مقاله به بررسی دکمه‌ها و امکانات موجود در فرم **فاکتور خرید** نرم‌افزار `حسابگر` می‌پردازیم.

---

## دکمه‌های اصلی فرم فاکتور خرید

|  ردیف |        عنوان |                                                        توضیح |
| ----: | -----------: | -----------------------------------------------------------: |
| **۱** |   **`خروج`** |             با زدن روی این قسمت، فرم فاکتور خرید بسته می‌شود. |
| **۲** | **`انصراف`** | اگر مایل به انصراف از عمل اخیر انجام شده باشید، گزینه **`انصراف`** را بزنید. |
| **۳** |  **`اصلاح`** | اگر گزینه **`اصلاح`** را بزنید، می‌توانید فاکتور خود را اصلاح کنید. |
| **۴** |   **`جدید`** | اگر بخواهید فاکتور جدیدی را ایجاد کنید، بر روی گزینه **`جدید`** کلیک کنید. |
| **۵** |    **`چاپ`** | اگر بخواهید از فاکتور مد نظر چاپ بگیرید، بر روی گزینه **`چاپ`** کلیک کنید. |

---

## امکانات مربوط به سند و گزارش‌گیری

|  ردیف |         عنوان |                                                        توضیح |
| ----: | ------------: | -----------------------------------------------------------: |
| **۶** |     **`ثبت`** | اگر بخواهید سند فاکتور انتخاب شده ثبت شود، بر روی گزینه **`ثبت`** کلیک کنید. |
| **۷** |  **`کاردکس`** | اگر بخواهید کاردکس کالای موجود در فاکتور را مشاهده کنید، روی کالا کلیک کرده و گزینه **`کاردکس`** را بزنید. |
| **۸** |    **`گردش`** | اگر بخواهید گردش حساب مشتری موجود در فاکتور را ببینید، نام یا کد مشتری را انتخاب کنید و بر روی گزینه **`گردش`** کلیک کنید. |
| **۹** | **`تغییرات`** | اگر بخواهید تغییرات اعمال شده توسط کاربران را مشاهده کنید، بر روی گزینه **`تغییرات`** کلیک کنید. |

## امکانات تکمیلی فرم فاکتور

|   ردیف |                   عنوان |                                                        توضیح |
| -----: | ----------------------: | -----------------------------------------------------------: |
| **۱۰** |             **`ارسال`** | اگر اقلام فاکتور خرید شما توسط خودروهای پخش به مشتری تحویل داده شود، برای ثبت اطلاعات راننده و خودرو بر روی گزینه **`ارسال`** کلیک کنید. |
| **۱۱** |        **`نمایش کلید`** | اگر بخواهید کنار فاکتور، پنل اعداد نمایش داده شود، بر روی گزینه **`نمایش کلید`** کلیک کنید. |
| **۱۲** |             **`پیوست`** | اگر بخواهید پیوست این فاکتور را در دیتابیس ذخیره کنید، بر روی **`پیوست`** کلیک کنید، دکمه **`جدید`** را بزنید، فایل خود را انتخاب کرده و تایید کنید. |
| **۱۳** |   **`تبدیل از فاکتور`** | اگر بخواهید یک رسید انبار مقداری خود را به فاکتور خرید تبدیل کنید، بر روی این گزینه کلیک کنید، سپس در لیست باز شده، رسید انبار مقداری مد نظر را انتخاب کرده و تایید کنید. |
| **۱۴** |          **`سبد کالا`** | اگر بخواهید قوانین سبد کالا بر روی یک یا چند ردیف فاکتور اعمال یا مشاهده شود، بر روی قسمت **`سبد کالا`** کلیک کنید. |
| **۱۵** |     **`ابطال/درجریان`** | اگر بخواهید فاکتور جاری را به ابطال شده و برعکس تبدیل کنید، بر روی قسمت **`ابطال/درجریان`** کلیک کنید. |
| **۱۶** | **`سامانه جامع تجارت`** | با کلیک بر روی این گزینه، می‌توانید اعمال مربوط به سامانه جامع تجارت این فاکتور را انجام دهید. |
| **۱۷** |             **`بیشتر`** | در این قسمت می‌توانید افزایش، کاهش یا جایگزینی قیمت‌ها را روی اقلام موجودی خود اعمال کنید. |
| **۱۸** |            **`راهنما`** | راهنمای استفاده از قسمت فاکتور خرید می‌باشد. با کلیک بر روی آن، توضیحات لازم در مورد نحوه کارکرد قسمت‌های مختلف ارائه شده است. |

## امکانات مربوط به مدیریت کالا و حساب

|   ردیف |              عنوان |                                                        توضیح |
| -----: | -----------------: | -----------------------------------------------------------: |
| **۱۹** |         **`حساب`** | اگر هنگام ورود فاکتور بخواهید نام حساب مشتری جدیدی وارد نرم‌افزار کنید، بر روی قسمت **`حساب`** کلیک کرده و حساب مد نظر را تعریف کنید. |
| **۲۰** |         **`کالا`** | اگر هنگام ورود فاکتور بخواهید نام کالای جدیدی وارد نرم‌افزار کنید، بر روی قسمت **`کالا`** کلیک کرده و کالای مد نظر را تعریف کنید. |
| **۲۱** |    **`وضع تخفیف`** | اگر بخواهید به یک ردیف کالای فاکتور بیش از یک درصد تخفیف ردیف اعمال کنید، از قسمت **`وضع تخفیف`** استفاده کنید. |
| **۲۲** |  **`به ترتیب کد`** |   کالاهای موجود در فاکتور خرید به ترتیب کد کالا مرتب می‌شوند. |
| **۲۳** | **`به ترتیب نام`** |  کالاهای موجود در فاکتور خرید به ترتیب نام کالا مرتب می‌شوند. |
| **۲۴** |        **`سریال`** |             در این قسمت، سریال ردیف کالاها نمایش داده می‌شود. |

## امکانات مالی و تسویه

|   ردیف |              عنوان |                                                        توضیح |
| -----: | -----------------: | -----------------------------------------------------------: |
| **۲۵** |   **`برگ پرداخت`** | اگر بخواهید به این فاکتور برگ پرداخت مرتبط کنید، از این گزینه استفاده کنید. |
| **۲۶** |     **`دفتر قسط`** | اگر بخواهید مبلغ این فاکتور را برای مشتری قسط‌بندی کنید، از این گزینه استفاده کنید. |
| **۲۷** |        **`تسویه`** | اگر مشتری مبلغ فاکتور را تسویه کند، برای صدور سند تسویه در سیستم بر روی گزینه **`تسویه`** کلیک کنید. |
| **۲۸** | **`ارسال (ردیف)`** | اگر بخواهید تنها بر روی یک یا چند ردیف ارسال فاکتور صورت گیرد، از این گزینه استفاده کنید. برای این کار، بر روی ردیف مد نظر کلیک کنید و گزینه **`ارسال`** را بزنید. |
| **۲۹** |     **`پرداختها`** | اگر بخواهید وضعیت پرداختی‌های ثبت شده برای این فاکتور را مشاهده کنید، بر روی گزینه **`پرداختها`** کلیک کنید. |

## امکانات جانبی و پیشرفته

|   ردیف |             عنوان |                                                        توضیح |
| -----: | ----------------: | -----------------------------------------------------------: |
| **۳۰** |      **`باسکول`** | برای ارتباط ترازو با فاکتور از این گزینه استفاده کنید. اگر ترازو به سیستم شما متصل باشد، وزن کالای روی باسکول در قسمت مقدار فاکتور فروش اضافه خواهد شد. |
| **۳۱** | **`سریال تجمعی`** | اگر بخواهید به ردیف کالاها سریال بدهید ولی شماره این سریال‌ها هیچ اهمیتی برای شما نداشته باشد، می‌توانید از سریال تجمیعی استفاده کنید. به این ترتیب که شما محدوده سریال را وارد می‌کنید و سیستم به دلخواه به ردیف کالاها سریال مربوطه را اختصاص می‌دهد. |
| **۳۲** |   **`وضع هزینه`** | در این قسمت، هزینه‌های سرشکن شده روی کالاها را مشاهده می‌کنید. |
| **۳۳** |  **`ارسال پیام`** | اگر بخواهید هنگام صدور فاکتور برای مشتری، پیامک ارسال شود، از گزینه **`ارسال پیام`** استفاده کنید. |
| **۳۴** |    **`مرتبط به`** | اگر این فاکتور از رسید مقداری کپی شده باشد، لیست فاکتور مرتبط را مشاهده کنید. |
| **۳۵** |    **`سری ساخت`** | اگر بخواهید برای ردیف کالای فاکتور سری ساخت تعریف و اختصاص دهید، بر روی گزینه **`سری ساخت`** کلیک کنید. |
| **۳۶** |  **`هزینه ردیف`** | اگر بخواهید برای ردیف فاکتور هزینه ردیف (ارزش افزوده ردیفی) تعریف کنید، بر روی این گزینه کلیک کنید. |
| **۳۷** |   **`چاپ بارکد`** | اگر بخواهید بارکدهای ردیف کالا را چاپ بگیرید، بر روی این گزینه کلیک کنید. |
