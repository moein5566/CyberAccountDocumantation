# اطلاعات فرم پیش‌نمایش ارسال به سامانه مودیان

**پاییز ۱۴۰۲**

در نرم‌افزار `حسابگر` شایگان سیستم، حین ارسال فاکتور به **سامانه مودیان**، یک فرم **پیش‌نمایش** به شما نشان داده می‌شود که شامل اطلاعات صورتحساب، طرف حساب و ... است. در ادامه بخش‌های مختلف این فرم توضیح داده خواهد شد.

---

## بخش‌های فرم پیش‌نمایش

|  شماره |                             عنوان |                                                        توضیح |
| -----: | --------------------------------: | -----------------------------------------------------------: |
|  **۱** |                        **`شرکت`** |     نام شرکت شما به همراه **شماره ملی** آن نمایش داده می‌شود. |
|  **۲** |   **`الگوی صورتحساب الکترونیکی`** | الگوی صورتحساب (**فروش**، **برگشت از فروش**، **صادرات** و ...) نمایش داده می‌شود. |
|  **۳** |                **`نوع صورتحساب`** | نوع صورتحساب را انتخاب نمایید (یکی از حالت‌های **نوع ۱**، **نوع ۲** یا **نوع ۳**). |
|  **۴** |                        **`حساب`** |                       حساب طرف حساب فاکتور نمایش داده می‌شود. |
|  **۵** |                    **`نوع حساب`** |          **حقیقی** یا **حقوقی** بودن حساب نشان داده شده است. |
|  **۶** |     **`شناسه ملی یا کد اقتصادی`** |        در صورت **حقوقی** بودن نوع حساب، این قسمت نمایان است. |
|  **۷** |                      **`کد ملی`** | در صورت **حقیقی** بودن نوع حساب، کد ملی طرف حساب نمایش داده می‌شود. |
|  **۸** |                **`مرجع اطلاعات`** | نوع حساب در برنامه (**حساب تفصیلی** - **تفصیلی شناور**) نمایش داده می‌شود. |
|  **۹** |                **`شماره فاکتور`** |                      شماره فاکتور برنامه نمایش داده شده است. |
| **۱۰** |                       **`تاریخ`** |                               تاریخ فاکتور را مشاهده نمایید. |
| **۱۱** |                  **`نوع فاکتور`** | نوع فاکتور (**فروش**، **برگشت از فروش**، **ابطالی**، **اصلاحی**) را مشاهده نمایید. |
| **۱۲** |                  **`جمع فاکتور`** |                                  جمع مبالغ فاکتور درج می‌شود. |
| **۱۳** |    **`جمع تخفیف ردیف‌های فاکتور`** |    مجموع تخفیف ردیف‌های اعمال شده در فاکتور را مشاهده نمایید. |
| **۱۴** |                 **`ارزش افزوده`** |                   میزان ارزش افزوده فاکتور نمایش داده می‌شود. |
| **۱۵** |             **`جمع خالص فاکتور`** |                                مبلغ خالص فاکتور درج شده است. |
| **۱۶** | **`شماره مالیاتی صورتحساب مرجع`** | در صورتی که صورتحساب شما **برگشت از فروش**، **ابطالی** یا **اصلاحی** باشد، شماره مالیاتی صورتحساب فروش مرتبط با آن نمایش داده می‌شود. |
| **۱۷** |                   **`روش تسویه`** | روش تسویه فاکتور (**نقد**، **نسیه**، **نقد-نسیه**) را انتخاب نمایید. |
| **۱۸** |                   **`آدرس سرور`** |                  آدرس سرور سامانه مودیان نمایش داده شده است. |
| **۱۹** |                         **`لغو`** | در صورتی که می‌خواهید ارسال را لغو نمایید، روی این گزینه کلیک کنید. |
| **۲۰** |                       **`ارسال`** | جهت ارسال صورتحساب به سامانه مودیان، روی این گزینه کلیک نمایید. |

---

## نکته

قبل از کلیک روی دکمه **`ارسال`**، تمام اطلاعات نمایش داده شده را **مطالعه** و **بررسی** کنید تا از صحت اطلاعات ارسالی اطمینان حاصل نمایید.
