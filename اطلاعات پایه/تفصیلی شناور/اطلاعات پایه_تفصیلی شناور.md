# معرفی تفصیلی شناور در نرم‌افزار حسابگر

## مقدمه

`تفصیلی شناور` یکی از امکانات نرم‌افزار `حسابگر` است که به شما امکان می‌دهد اطلاعات تکمیلی را به‌صورت **دسته‌بندی شده** به حساب‌ها اضافه کنید. با استفاده از این قابلیت، می‌توانید اطلاعات مشتریان، فروشندگان، پروژه‌ها و ... را به‌صورت تفکیک‌شده مدیریت کنید.

> **نکته مهم**: قبل از ایجاد تفصیلی شناور، ابتدا باید `گروه تفصیلی شناور` را ایجاد کنید. اگر از قبل ساخته شده است، می‌توانید ادامه مسیر را دنبال کنید.

---

# بخش اول: گروه تفصیلی شناور

## نحوه ایجاد گروه تفصیلی شناور

برای معرفی گروه تفصیلی شناور:

- از منوی `اطلاعات پایه` -> `معرفی تفصیلی شناور و گروه` -> `معرفی گروه تفصیلی شناور` را انتخاب کنید.

---

### مراحل ایجاد گروه تفصیلی شناور

#### مرحله ۱: ایجاد گروه جدید
- از نوار ابزار بالای فرم، دکمه `جدید` را کلیک کنید.

---

#### مرحله ۲: وارد کردن کد گروه
- `کد گروه تفصیلی شناور` را وارد کنید.
- کلید `Enter` را بزنید.

---

#### مرحله ۳: وارد کردن نام گروه
- `نام گروه تفصیلی شناور` را وارد کنید.
- کلید `Enter` را بزنید.

---

#### مرحله ۴: ذخیره گروه
- از نوار ابزار بالای فرم، دکمه `ذخیره` را کلیک کنید.

---

# بخش دوم: معرفی تفصیلی شناور

## مسیر دسترسی

برای معرفی تفصیلی شناور:

- از منوی `اطلاعات پایه` -> `معرفی تفصیلی شناور و گروه` -> `معرفی تفصیلی شناور` را انتخاب کنید.
- یا از ترکیب کلیدهای `Ctrl+U` استفاده کنید.

---

## مراحل معرفی تفصیلی شناور جدید

### مرحله ۱: ایجاد تفصیلی جدید
- از نوار ابزار بالای فرم، دکمه `جدید` را کلیک کنید.

---

### مرحله ۲: وارد کردن کد تفصیلی
- `کد تفصیلی شناور` را وارد کنید.
- کلید `Enter` را بزنید.

---

### مرحله ۳: وارد کردن نام تفصیلی
- `نام تفصیلی شناور` را وارد کنید.
- کلید `Enter` را بزنید.

---

### مرحله ۴: انتخاب گروه تفصیلی
- `گروه تفصیلی شناور` را که این تفصیلی زیرگروه آن است، انتخاب کنید.

---

## اطلاعات تکمیلی تفصیلی شناور

برای تفصیلی شناور می‌توانید یک سری اطلاعات تکمیلی وارد کنید (اختیاری):

|                               فیلد |                            توضیح |
| ---------------------------------: | -------------------------------: |
|                          `توضیحات` |          توضیحات مربوط به تفصیلی |
|               `نماینده فروش ۱ و ۲` |             نمایندگان فروش مرتبط |
|                 `واحد پولی پیش‌فرض` | واحد پولی پیش‌فرض برای این تفصیلی |
|                     `درصد کمیسیون` |              درصد کمیسیون مربوطه |
|          `سقف بدهکاری و بستانکاری` |     سقف مجاز بدهکاری و بستانکاری |
| `سقف بدهکاری و بستانکاری با اسناد` |   سقف مجاز با در نظر گرفتن اسناد |

---

## اطلاعات جزئی تفصیلی شناور

در پنجره `اطلاعات جزئی` می‌توانید اطلاعات زیر را وارد کنید:

|        فیلد |                                    توضیح |
| ----------: | ---------------------------------------: |
|      `آدرس` |                                آدرس کامل |
|      `تلفن` |                               شماره تلفن |
|       `فکس` |                                شماره فکس |
| `سطح تخفیف` |                         سطح تخفیف مربوطه |
|     `و ...` | سایر فیلدهای قابل استفاده در طراحی فرم‌ها |

---

## فعالیت حساب تفصیلی شناور

در قسمت مربوط به `فعالیت حساب تفصیلی شناور`، دقیقاً مشابه فعالیت حساب برای حساب‌های تفصیلی، می‌توانید:
- گردش حساب این تفصیلی شناور را مشاهده کنید.
- تراکنش‌های مربوط به آن را بررسی کنید.

---

# بخش سوم: نمودار سطحی تفصیلی شناور

## مشاهده نمودار سطحی

برای مشاهده `نمودار سطحی تفصیلی شناور`:

- از منوی `اطلاعات پایه` → `معرفی تفصیلی شناور و گروه` → `معرفی تفصیلی شناور` را انتخاب کنید.
- سپس `نمودار سطحی تفصیلی شناور` را انتخاب کنید.

---

### امکانات نمودار سطحی

در این قسمت:
- `گروه‌های تفصیلی شناور` را به همراه `ساختار درختی تفصیلی شناور` که در مرحله قبل تعریف شده است، مشاهده می‌کنید.
- می‌توانید روابط سلسله‌مراتبی بین گروه‌ها و تفصیلی‌ها را به‌صورت گرافیکی مشاهده کنید.

---

# بخش چهارم: اتصال تفصیلی شناور به حساب

بعد از اینکه تفصیلی شناور ایجاد شد، باید آن را به حساب مورد نظر متصل کنید.

### مراحل اتصال
1. از قسمت `معرفی حساب‌ها` → `اطلاعات کلی` بروید.
2. نام حسابی را که می‌خواهید تفصیلی شناور به آن وصل شود، انتخاب کنید.
3. گزینه `گروه تفصیلی شناور` را بزنید و گروه مربوطه را انتخاب کنید.

---

## نکات مهم درباره اتصال

|                  نکته |                                                        توضیح |
| --------------------: | -----------------------------------------------------------: |
|        `اتصال اجباری` |    تفصیلی شناور باید حتماً به یک `گروه تفصیلی شناور` وصل باشد |
|  `اتصال گروه به حساب` |          گروه تفصیلی شناور باید به یک `حساب تفصیلی` متصل شود |
| `چند گروه در نسخه ۱۰` | در `نسخه ۱۰` حسابگر، می‌توان برای یک حساب تفصیلی، `چند گروه تفصیلی شناور` وصل کرد |

---

## نکات مهم

|                  نکته |                                                        توضیح |
| --------------------: | -----------------------------------------------------------: |
|         `گروه تفصیلی` | قبل از تعریف تفصیلی شناور، باید `گروه تفصیلی` آن را تعریف کنید |
|       `اتصال به حساب` | تفصیلی شناور باید به یک گروه تفصیلی و آن گروه به یک حساب متصل شود |
| `چند گروه در نسخه ۱۰` | در نسخه ۱۰، امکان اتصال چند گروه تفصیلی شناور به یک حساب وجود دارد |
|      `اطلاعات تکمیلی` |                         وارد کردن اطلاعات تکمیلی اجباری نیست |
|        `اطلاعات جزئی` |         اطلاعاتی مانند آدرس، تلفن و ... در این بخش ثبت می‌شود |
|         `فعالیت حساب` |                امکان مشاهده گردش حساب تفصیلی شناور وجود دارد |
|         `کلید میانبر` |                         `Ctrl+U` برای دسترسی سریع به این بخش |

---

## جمع‌بندی

- `تفصیلی شناور` یکی از امکانات مهم نرم‌افزار حسابگر برای مدیریت اطلاعات تکمیلی حساب‌ها است.
- قبل از تعریف تفصیلی شناور، باید `گروه تفصیلی` آن را تعریف کنید.
- تفصیلی شناور باید به یک `گروه تفصیلی شناور` و آن گروه به یک `حساب تفصیلی` متصل شود.
- در `نسخه ۱۰` حسابگر، می‌توان برای یک حساب تفصیلی، `چند گروه تفصیلی شناور` وصل کرد.
- اطلاعات تکمیلی مانند `آدرس`، `تلفن`، `نماینده فروش` و ... را می‌توان برای هر تفصیلی ثبت کرد.
- امکان مشاهده `گردش حساب` و `فعالیت` تفصیلی شناور وجود دارد.
- با استفاده از `نمودار سطحی`، می‌توان ساختار سلسله‌مراتبی تفصیلی‌ها را مشاهده کرد.
- کلید میانبر `Ctrl+U` دسترسی سریع به این بخش را فراهم می‌کند.
