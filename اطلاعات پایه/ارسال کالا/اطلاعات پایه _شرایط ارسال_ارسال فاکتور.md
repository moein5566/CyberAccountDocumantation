# شرایط ارسال کالا در نرم‌افزار حسابگر

## مقدمه

`ارسال کالا` یکی از امکانات نرم‌افزار حسابداری `حسابگر` **نسخه ۹** است که با استفاده از آن می‌توانید انواع خودروها را به همراه راننده‌هایشان که در یک شرکت یا فروشگاه مسئولیت حمل کالاها را بر عهده دارند، تعریف کنید.

این امکان این قابلیت را فراهم می‌آورد که کاربران بتوانند برای هر ارسال، لیست و تعداد کالاها به همراه شرایط حمل کالا (مانند نام راننده و ماشین ارسالی) را مشخص و از وضعیت ارسال گزارش تهیه کنند.

---

# بخش اول: تعریف خودروها

برای استفاده از این امکان، ابتدا باید `خودروها` و اطلاعات مربوط به آنها را در سیستم ثبت کنید.

## مسیر دسترسی

- از مسیر `اطلاعات پایه` -> `شرایط ارسال` -> `تعریف خودروها` را انتخاب کنید.

---

## مراحل تعریف خودرو جدید

### مرحله ۱: ایجاد خودرو جدید
- در فرم باز شده، روی دکمه `جدید` کلیک کنید.

---

### مرحله ۲: وارد کردن اطلاعات خودرو

|               فیلد |                                          توضیح |
| -----------------: | ---------------------------------------------: |
|      `شماره خودرو` |                       شماره خودرو را وارد کنید |
|        `نام خودرو` |                         نام خودرو را وارد کنید |
| `شماره پلاک خودرو` |        شماره پلاک خودرو را وارد کنید (اختیاری) |
|     `راننده خودرو` | نام راننده خودرو را از لیست حساب‌ها انتخاب کنید |
|    `اطلاعات خودرو` |    اطلاعات تکمیلی خودرو را وارد کنید (اختیاری) |
|        `وزن خودرو` |               وزن خودرو را وارد کنید (اختیاری) |
| `حداکثر وزن ارسال` |    حداکثر وزن قابل حمل توسط خودرو را وارد کنید |
| `حداکثر حجم ارسال` |    حداکثر حجم قابل حمل توسط خودرو را وارد کنید |

---

### مرحله ۳: ذخیره خودرو
- بعد از تعیین موارد مورد نظر، روی دکمه `ذخیره` کلیک کنید.

---

# بخش دوم: وضعیت ارسال فاکتورها

برای ارسال یک فاکتور یا چند فاکتور به‌صورت همزمان:

## مسیر دسترسی

- از مسیر `اطلاعات پایه` -> `شرایط ارسال` -> `وضعیت ارسال فاکتورها` را انتخاب کنید.
- یا بر روی دکمه `ارسال` موجود در بالای فرم فاکتور کلیک کرده و سپس دکمه `ارسال` را انتخاب کنید.

---

## مراحل ثبت ارسال جدید

### مرحله ۱: ایجاد ارسال جدید
- در فرم باز شده، روی دکمه `جدید` کلیک کنید.

---

### مرحله ۲: تکمیل اطلاعات ارسال

|                 فیلد |                                                        توضیح |
| -------------------: | -----------------------------------------------------------: |
|    `تاریخ ارسال کلی` |                                     تاریخ ارسال را وارد کنید |
|       `تاریخ دریافت` |      تاریخ تحویل کالاها به مشتریان را بعد از ارسال وارد کنید |
| `شماره یا نام خودرو` |                     خودروی مورد نظر جهت ارسال را انتخاب کنید |
|             `راننده` | در صورت مشخص بودن در معرفی خودرو، اطلاعات راننده نمایش داده می‌شود (قابل تغییر) |
|   `کد و نام فروشنده` | فروشنده‌ای که طبق قوانین کمیسیون، پورسانت به وی تعلق می‌گیرد را انتخاب کنید |

> **نکته**: با انتخاب دکمه `اعمال نماینده در فاکتورهای مرتبط`، نام نماینده انتخابی در تمام فاکتورهایی که در قسمت فاکتورهای مرتبط انتخاب شده‌اند، اعمال می‌شود.

---

### مرحله ۳: انتخاب فاکتورهای مرتبط

- با انتخاب دکمه ذره‌بین، لیست فاکتورهایی که تمام ردیف‌ها یا بخشی از ردیف‌های آنها ارسال نشده، نمایش داده می‌شود.
- با استفاده از کلید `Insert`، می‌توانید فاکتورهای مورد نظر را انتخاب کنید.
- روی دکمه `تایید` کلیک کنید.

> **نکته**: با انتخاب دکمه `جستجوی پیشرفته`، می‌توانید در فرم باز شده با استفاده از فیلترهای قرار داده شده، فاکتورهای مورد نظر جهت ارسال را انتخاب کنید.

---

### مرحله ۴: مشاهده زبانه‌های ارسال

|                       زبانه |                                                        توضیح |
| --------------------------: | -----------------------------------------------------------: |
|        `تمام ردیف‌های ارسال` |          تمامی ردیف‌های فاکتورهای انتخاب‌شده نمایش داده می‌شوند |
|      `فاکتورهای فروش مرتبط` |            لیست فاکتورهای مربوط به هر ارسال نمایش داده می‌شود |
|                `قسمت جمع‌ها` | لیست کالاهای مرتبط به فاکتورها به صورت تجمیعی نمایش داده می‌شود |
|    `برگشت از فروش‌های مرتبط` | لیست فاکتورهای برگشت از فروش مرتبط با ارسال نمایش داده می‌شود |
| `برگه دریافت لیست‌های مرتبط` |          لیست برگه دریافت‌های مرتبط با ارسال نمایش داده می‌شود |

---

### مرحله ۵: اختصاص به دستگاه (ویژه نسخه ۱۰ پخش)

چنانچه از برنامه `حسابگر ویژه پخش نسخه ۱۰` استفاده می‌کنید:

- با استفاده از دکمه `اختصاص به دستگاه`، می‌توانید یک ارسال را به یک راننده اختصاص دهید.
- بعد از اختصاص، راننده در برنامه `PPC` می‌تواند ارسال‌هایی که باید به مشتری تحویل دهد را مشاهده کند.
- در قسمت `نام دستگاه`، دستگاه راننده مورد نظر را انتخاب کنید.

---

### مرحله ۶: ارسال پیام کوتاه

با استفاده از دکمه `پیام کوتاه` موجود در این فرم، می‌توانید برای مشتریان یا رانندگان، با توجه به قالب‌های طراحی‌شده، پیام کوتاه ارسال کنید.

---

## نکات مهم

|               نکته |                                                 توضیح |
| -----------------: | ----------------------------------------------------: |
|           `نسخه ۹` | امکان ارسال کالا در `نسخه ۹` به بالا قابل استفاده است |
|      `تعریف خودرو` |              قبل از ارسال، باید خودروها را تعریف کنید |
|       `ارسال سریع` |           امکان ارسال سریع برای تسریع در فرآیند ارسال |
| `اختصاص به دستگاه` |   در نسخه پخش، امکان اختصاص ارسال به راننده وجود دارد |
|          `گزارشات` |                 گزارشات متنوع برای پیگیری وضعیت ارسال |
|       `پیام کوتاه` |          امکان ارسال پیام کوتاه به مشتریان و رانندگان |

---

### ثبت ارسال جدید

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ | مسیر `اطلاعات پایه` → `شرایط ارسال` → `وضعیت ارسال فاکتورها` |
|     ۲ |                                    روی دکمه `جدید` کلیک کنید |
|     ۳ |       `تاریخ ارسال`، `تاریخ دریافت` و `خودرو` را انتخاب کنید |
|     ۴ |                فاکتورهای مورد نظر را با `Insert` انتخاب کنید |
|     ۵ | در صورت نیاز، به دستگاه اختصاص دهید یا پیام کوتاه ارسال کنید |
|     ۶ |                                        روی `ذخیره` کلیک کنید |

---

## جمع‌بندی

- `ارسال کالا` یکی از امکانات نسخه ۹ حسابگر برای مدیریت حمل کالاها است.
- ابتدا باید `خودروها` و اطلاعات مربوط به آنها را تعریف کنید.
- امکان ارسال `تکی`، `گروهی` و `سریع` وجود دارد.
- در نسخه پخش، امکان `اختصاص ارسال به دستگاه` راننده وجود دارد.
- `گزارشات` متنوعی برای پیگیری وضعیت ارسال قابل تهیه است.
