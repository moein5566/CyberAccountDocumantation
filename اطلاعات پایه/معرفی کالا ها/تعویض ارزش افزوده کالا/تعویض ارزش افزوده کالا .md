# تغییر گروهی ارزش افزوده کالاها

## مقدمه

در برنامه `حسابگر`، شما می‌توانید `ارزش افزوده` گروهی از کالاها را به‌صورت **دسته‌ای** تغییر دهید. این قابلیت به شما امکان می‌دهد تا در زمان صرفه‌جویی کرده و از انجام تغییرات تکی برای هر کالا بی‌نیاز شوید.

---

## مسیر دسترسی

برای دسترسی به این بخش، از مسیر زیر استفاده کنید:

- `اطلاعات پایه` -> `معرفی کالاها` -> `تعویض ارزش افزوده کالاها`

---

## مراحل تغییر گروهی ارزش افزوده

برای `تغییر گروهی ارزش افزوده` کالاها، مراحل زیر را دنبال کنید:

### مرحله ۱: ورود به بخش تعویض ارزش افزوده کالاها
- از منوی `اطلاعات پایه` -> `معرفی کالاها` -> `تعویض ارزش افزوده کالاها` را انتخاب کنید.

---

### مرحله ۲: انتخاب کالاها

می‌توانید کالاهای مورد نظر را به یکی از روش‌های زیر انتخاب کنید:

|               روش انتخاب |                                                توضیح |
| -----------------------: | ---------------------------------------------------: |
|              `گروه کالا` |                      انتخاب تمام کالاهای یک گروه خاص |
|           `زیرگروه کالا` |                   انتخاب تمام کالاهای یک زیرگروه خاص |
|  `کد کالا از ... تا ...` |              انتخاب کالاها بر اساس **دامنه کد** کالا |
| `نام کالا از ... تا ...` |             انتخاب کالاها بر اساس **دامنه نام** کالا |
|             `انتخاب تکی` | انتخاب کالاها به‌صورت تکی با استفاده از کلید `Insert` |

> **نکته**: برای انتخاب چند کالا به‌صورت تکی، از کلید `Insert` استفاده کنید. همچنین گزینه‌های `کد کالا از` و `نام کالا از` برای انتخاب دامنه‌ای کالاها وجود دارد.

---

### مرحله ۳: تغییر ارزش افزوده
- پس از انتخاب کالاها، روی دکمه پایین صفحه کلیک کنید.
- `نوع ارزش افزوده` مورد نظر را با `درصد` دلخواه انتخاب کنید.

---

### مرحله ۴: تأیید تغییرات
- پس از انتخاب نوع و درصد ارزش افزوده، تغییرات را تأیید کنید.
- تمام کالاهای انتخاب‌شده، ارزش افزوده جدید را دریافت می‌کنند.

---

## نکات مهم

|               نکته |                                                        توضیح |
| -----------------: | -----------------------------------------------------------: |
| `صرفه‌جویی در زمان` |      با این روش، نیازی به تغییر تکی ارزش افزوده هر کالا نیست |
|     `انتخاب گروهی` | امکان انتخاب بر اساس `گروه کالا`، `زیرگروه کالا`، `دامنه کد`، `دامنه نام` یا `تکی` وجود دارد |
|      `کلید Insert` | برای انتخاب چند کالا به‌صورت تکی از کلید `Insert` استفاده کنید |
|   `دامنه کد و نام` | با استفاده از `کد کالا از` و `نام کالا از` می‌توانید کالاها را به‌صورت دامنه‌ای انتخاب کنید |
|    `تغییر یکپارچه` |    تمام کالاهای انتخاب‌شده، ارزش افزوده جدید را دریافت می‌کنند |

---

## خلاصه گام‌ها

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ | منوی `اطلاعات پایه` → `معرفی کالاها` → `تعویض ارزش افزوده کالاها` |
|     ۲ | کالاهای مورد نظر را انتخاب کنید (گروهی، زیرگروهی، دامنه‌ای یا تکی با `Insert`) |
|     ۳ |                                روی دکمه پایین صفحه کلیک کنید |
|     ۴ |           `نوع` و `درصد` ارزش افزوده مورد نظر را انتخاب کنید |
|     ۵ |                                        تغییرات را تأیید کنید |

---

## جمع‌بندی

- `تغییر گروهی ارزش افزوده` یکی از امکانات کارآمد برنامه حسابگر برای مدیریت سریع کالاها است.
- مسیر دسترسی: `اطلاعات پایه` → `معرفی کالاها` → `تعویض ارزش افزوده کالاها`
- با این روش، می‌توانید ارزش افزوده تعداد زیادی کالا را در کمترین زمان تغییر دهید.
- انتخاب کالاها به‌صورت `گروهی`، `زیرگروهی`، `دامنه‌ای (کد یا نام)` یا `تکی (با Insert)` امکان‌پذیر است.
- در صورت عدم وجود درصد ارزش افزوده مورد نظر، از لینک آموزش ثبت ارزش افزوده استفاده کنید.
