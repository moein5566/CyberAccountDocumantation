# مدیریت دسترسی به نقش‌ها در نرم‌افزار حسابگر

## مقدمه

> **توجه**: این قسمت مخصوص **نسخه ۱۰** حسابگر است.

به‌صورت پیش‌فرض، اکثر آیتم‌های این بخش **غیرفعال** می‌باشند و در صورت نیاز میتوانید آنها را فعال کنید.

---

## خطای عدم دسترسی به نقش

در صورتی که کاربری با پیغام زیر مواجه شد:

> **"نام کاربری شما، نقش استفاده از این امکان را ندارد."**

برای مثال هنگام استفاده از `سامانه مودیان` یا `ارسال فاکتور به سامانه مودیان`، باید به مسیر زیر مراجعه کنید:

- از مسیر `اطلاعات پایه` -> `مدیریت سیستم` -> `دسترسی به نقش‌ها` را انتخاب کنید.

## نکات مهم

|                  نکته |                                                        توضیح |
| --------------------: | -----------------------------------------------------------: |
|             `نسخه ۱۰` |         این قابلیت فقط در `نسخه ۱۰` به بالا قابل استفاده است |
| `غیرفعال بودن پیش‌فرض` |                      اکثر آیتم‌ها به‌صورت پیش‌فرض غیرفعال هستند |
|     `فعال‌سازی دسترسی` |       برای استفاده از هر امکان، باید نقش مربوطه را فعال کنید |
|           `پیغام خطا` | در صورت مشاهده خطای "نقش استفاده از این امکان را ندارد"، به این بخش مراجعه کنید |

## خلاصه گام‌ها

| مرحله |                                                      اقدام |
| ----: | ---------------------------------------------------------: |
|     ۱ | مسیر `اطلاعات پایه` -> `مدیریت سیستم` -> `دسترسی به نقش‌ها` |
|     ۲ |               کاربر یا گروه کاربری مورد نظر را انتخاب کنید |
|     ۳ |                   نقش/دسترسی مورد نظر را از لیست پیدا کنید |
|     ۴ |                   تیک مربوطه را برای فعال‌سازی دسترسی بزنید |
|     ۵ |                                      تغییرات را ذخیره کنید |

---

## جمع‌بندی

- `دسترسی به نقش‌ها` یکی از امکانات **نسخه ۱۰** حسابگر برای مدیریت دقیق دسترسی‌های کاربران است.
- به‌صورت پیش‌فرض، اکثر دسترسی‌ها غیرفعال هستند و باید به‌صورت دستی فعال شوند.
- در صورت مشاهده خطای "نقش استفاده از این امکان را ندارد"، باید دسترسی مربوطه را در این بخش فعال کنید.
- این بخش شامل دسترسی‌های متنوعی مانند `سامانه مودیان`، `سامانه جامع تجارت`، `افزونه رستوران`، `اهداف فروش`، `مغایرت‌گیری` و ... است.
