# معرفی استفاده‌کنندگان و مدیریت دسترسی در نرم‌افزار حسابگر

## مقدمه

شرکت‌ها با توجه به سیاست‌های کاری خود جهت کنترل امور کاربران و امنیت اطلاعات، نیازمند معرفی چندین کاربر و بر اساس نوع کاربری آنها، نیازمند تعریف `چندین سطح دسترسی متفاوت` برای استفاده از نرم‌افزار حسابداری هستند.

در نرم‌افزار حسابداری `حسابگر` با امکان `مدیریت دسترسی` می‌توانید:
- به **تعداد نامحدود** کاربر تعریف کنید.
- کاربران را به `گروه‌های کاری متفاوت` اختصاص دهید.
- برای هر گروه، `دسترسی‌های متفاوت` برای استفاده از برنامه تعریف کنید.

---

## بخش‌های مدیریت کاربران

مدیریت کاربران در نرم‌افزار حسابگر شامل **سه بخش** اصلی است:

|                   بخش |                                                      توضیح |
| --------------------: | ---------------------------------------------------------: |
|      `استفاده‌کنندگان` | لیست کاربران تعریف‌شده، ایجاد، اصلاح، حذف و مشاهده فعالیت‌ها |
|               `منوها` |    تنظیم دسترسی‌های کاربران به منوها و آیتم‌های مختلف برنامه |
| `کاربران داخل برنامه` |          مشاهده کاربران آنلاین و امکان اخراج آنها از سیستم |

---

# بخش اول: استفاده‌کنندگان

## مسیر دسترسی

- از منوی `اطلاعات پایه` -> `مدیریت سیستم` -> `معرفی استفاده‌کنندگان` را انتخاب کنید.

---

## امکانات این بخش

### ۱. لیست کاربران
- در این قسمت، لیست تمام کاربران تعریف‌شده در برنامه نمایش داده می‌شود.
- می‌توانید کاربر `جدید` ایجاد کنید، `اصلاح` کنید، `حذف` کنید یا `تصحیح` کنید.

---

### ۲. فعالیت‌های استفاده‌کننده
با انتخاب گزینه `فعالیت‌های استفاده‌کننده`، می‌توانید مشاهده کنید که هر کاربر در برنامه چه اقداماتی انجام داده است:

|                  فعالیت |                                                 توضیح |
| ----------------------: | ----------------------------------------------------: |
| `ورود به فاکتور یا سند` | مشاهده اینکه کاربر به کدام فاکتور یا سند دسترسی داشته |
|                 `اصلاح` |            مشاهده اینکه کاربر چه مواردی را اصلاح کرده |
|                   `حذف` |              مشاهده اینکه کاربر چه مواردی را حذف کرده |

---

### ۳. کپی دسترسی‌ها و تنظیمات کاربر
با استفاده از گزینه `کپی دسترسی‌ها و تنظیمات کاربر`، می‌توانید:
- تنظیمات دسترسی اعمال‌شده را از یک کاربر به کاربر دیگر `کپی` کنید.
- این کار باعث صرفه‌جویی در زمان و جلوگیری از تنظیمات تکراری می‌شود.

---

# بخش دوم: منوها (تنظیم دسترسی)

## مسیر دسترسی
- در بخش `استفاده‌کنندگان`، کاربر مورد نظر را انتخاب کنید.
- به زبانه `منوها` بروید.

---

## تنظیم دسترسی به منوها

در این قسمت می‌توانید برای هر کاربر، دسترسی به منوهای مختلف برنامه را تعیین کنید:

|                 سربرگ |                    توضیح |
| --------------------: | -----------------------: |
|               `سیستم` | دسترسی به تنظیمات سیستمی |
|              `پرونده` |     دسترسی به بخش پرونده |
| `ویرایش اطلاعات پایه` |   دسترسی به اطلاعات پایه |
|       `عملیات روزانه` |  دسترسی به عملیات روزانه |
|               `و ...` |      سایر سربرگ‌های موجود |

---

### نحوه تنظیم دسترسی
- برای هر کاربر، از بین `سربرگ‌های` پایین صفحه، بخش مورد نظر را انتخاب کنید.
- `آیتم‌هایی` که کاربر نباید به آنها دسترسی داشته باشد را انتخاب کرده و گزینه `عدم دسترسی` را بزنید.

> **نکته**: این روش برای زمانی است که می‌خواهید برای `هر کاربر به صورت تکی` دسترسی تعیین کنید.

---

# بخش سوم: کاربران داخل برنامه

## مسیر دسترسی
- در بخش `استفاده‌کنندگان`، به زبانه `کاربران داخل برنامه` بروید.

---

## امکانات این بخش

در این قسمت می‌توانید کاربرانی که در حال حاضر در سیستم هستند را مشاهده کنید:

| اطلاعات |                                       توضیح |
| ------: | ------------------------------------------: |
| `سیستم` | مشاهده کنید کاربر با چه سیستمی وارد شده است |
|  `زمان` |  مشاهده کنید کاربر در چه زمانی وارد شده است |
|   `فرم` |    مشاهده کنید کاربر در کدام فرم برنامه است |
|  `دوره` |       مشاهده کنید کاربر در چه دوره مالی است |

---

### اخراج کاربر
- در صورت نیاز، کاربر مورد نظر را انتخاب کنید.
- با انتخاب گزینه `اخراج کاربر`، کاربر را از سیستم خارج کنید.

---

## نکات مهم

|                    نکته |                                              توضیح |
| ----------------------: | -------------------------------------------------: |
|   `تعداد نامحدود کاربر` |           امکان تعریف تعداد نامحدود کاربر در سیستم |
|          `گروه‌های کاری` |         امکان اختصاص کاربران به گروه‌های کاری مختلف |
|            `دسترسی تکی` |       امکان تنظیم دسترسی برای هر کاربر به‌صورت مجزا |
|            `کپی دسترسی` | امکان کپی تنظیمات دسترسی از یک کاربر به کاربر دیگر |
| `مشاهده کاربران آنلاین` |       امکان مشاهده کاربرانی که در سیستم حضور دارند |
|           `اخراج کاربر` |        امکان خارج کردن کاربر از سیستم در صورت نیاز |

---

## خلاصه گام‌ها

### ایجاد کاربر جدید

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ | منوی `اطلاعات پایه` → `مدیریت سیستم` → `معرفی استفاده‌کنندگان` |
|     ۲ |                                    روی دکمه `جدید` کلیک کنید |
|     ۳ |                                   اطلاعات کاربر را وارد کنید |
|     ۴ |                                   گروه امنیتی را انتخاب کنید |
|     ۵ |                                        روی `ذخیره` کلیک کنید |

---

### کپی دسترسی‌ها

| مرحله |                                               اقدام |
| ----: | --------------------------------------------------: |
|     ۱ |                           کاربر مبدا را انتخاب کنید |
|     ۲ | گزینه `کپی دسترسی‌ها و تنظیمات کاربر` را انتخاب کنید |
|     ۳ |                           کاربر مقصد را انتخاب کنید |
|     ۴ |                                          تأیید کنید |

---

### اخراج کاربر

| مرحله |                                اقدام |
| ----: | -----------------------------------: |
|     ۱ | به زبانه `کاربران داخل برنامه` بروید |
|     ۲ |        کاربر مورد نظر را انتخاب کنید |
|     ۳ |         گزینه `اخراج کاربر` را بزنید |

---

## جمع‌بندی

- `مدیریت کاربران` در نرم‌افزار حسابگر شامل سه بخش اصلی است: `استفاده‌کنندگان`، `منوها` و `کاربران داخل برنامه`.
- امکان تعریف `تعداد نامحدود کاربر` با `سطوح دسترسی متفاوت` وجود دارد.
- با استفاده از `کپی دسترسی‌ها`، می‌توان تنظیمات را از یک کاربر به کاربر دیگر منتقل کرد.
- در بخش `کاربران داخل برنامه`، می‌توان کاربران آنلاین را مشاهده و در صورت نیاز آنها را اخراج کرد.
