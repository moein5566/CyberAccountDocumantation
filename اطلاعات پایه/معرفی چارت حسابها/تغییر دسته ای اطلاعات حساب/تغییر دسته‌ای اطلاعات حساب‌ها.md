# تغییر دسته‌ای اطلاعات حساب‌ها

## مقدمه

در نرم‌افزار `حسابگر`، امکان `تغییر دسته‌ای` اطلاعات حساب‌ها وجود دارد. این قابلیت به شما کمک می‌کند تا بدون نیاز به ویرایش تک‌به‌تک حساب‌ها، تغییرات مورد نظر را به‌صورت **گروهی** اعمال کنید.

---

## انواع تغییر دسته‌ای

تغییر دسته‌ای اطلاعات حساب‌ها به **سه قسمت** تقسیم می‌شود:

|                نوع تغییر |                                  توضیح |
| -----------------------: | -------------------------------------: |
| `تغییر دسته‌ای نماینده ۱` |   تغییر نماینده فروش اول به‌صورت دسته‌ای |
| `تغییر دسته‌ای نماینده ۲` |   تغییر نماینده فروش دوم به‌صورت دسته‌ای |
|       `تغییر دسته‌ای محل` | تغییر محل (منطقه) حساب‌ها به‌صورت دسته‌ای |

---

## مراحل تغییر دسته‌ای

### مرحله ۱: انتخاب حساب‌ها

برای انتخاب حساب‌های مورد نظر، می‌توانید از روش‌های زیر استفاده کنید:

|             روش انتخاب |                                                        توضیح |
| ---------------------: | -----------------------------------------------------------: |
| `انتخاب تکی با Insert` | با استفاده از کلید `Insert`، حساب‌های مورد نظر را یکی‌یکی انتخاب کنید |
|        `انتخاب سرگروه` |                          انتخاب تمام حساب‌های یک `سرگروه` خاص |
|            `انتخاب کل` |                                          انتخاب `همه` حساب‌ها |
|          `انتخاب معین` |                       انتخاب تمام حساب‌های یک `حساب معین` خاص |

---

### مرحله ۲: اعمال تغییرات

پس از انتخاب حساب‌ها، می‌توانید تغییرات مورد نظر را به‌صورت دسته‌ای اعمال کنید:
- `نماینده فروش ۱` را تغییر دهید.
- `نماینده فروش ۲` را تغییر دهید.
- `محل (منطقه)` حساب‌ها را تغییر دهید.

---

## نکات مهم

|               نکته |                                                        توضیح |
| -----------------: | -----------------------------------------------------------: |
| `انتخاب با Insert` | برای انتخاب چند حساب به‌صورت تکی، از کلید `Insert` استفاده کنید |
|     `انتخاب گروهی` |      امکان انتخاب بر اساس `سرگروه`، `کل` یا `معین` وجود دارد |
| `صرفه‌جویی در زمان` |                با این روش، نیازی به تغییر تک‌به‌تک حساب‌ها نیست |
|     `سه نوع تغییر` | تغییر `نماینده ۱`، `نماینده ۲` و `محل` به‌صورت دسته‌ای امکان‌پذیر است |

---

## خلاصه گام‌ها

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ |                     به بخش `تغییر دسته‌ای اطلاعات حساب` بروید |
|     ۲ | حساب‌های مورد نظر را انتخاب کنید (با `Insert`، `سرگروه`، `کل` یا `معین`) |
|     ۳ | نوع تغییر را انتخاب کنید (`نماینده ۱`، `نماینده ۲` یا `محل`) |
|     ۴ |                                      مقدار جدید را وارد کنید |
|     ۵ |                                        تغییرات را تأیید کنید |

---

## جمع‌بندی

- `تغییر دسته‌ای اطلاعات حساب‌ها` یکی از امکانات کارآمد نرم‌افزار حسابگر برای مدیریت سریع حساب‌ها است.
- این قابلیت در **سه نوع** (`نماینده ۱`، `نماینده ۲` و `محل`) قابل استفاده است.
- انتخاب حساب‌ها به‌صورت `تکی (با Insert)`، `سرگروه`، `کل` یا `معین` امکان‌پذیر است.
- با این روش، می‌توانید تغییرات را به‌صورت **گروهی** و در کمترین زمان اعمال کنید.

---

> **توجه**: در صورت نیاز به راهنمایی بیشتر، با واحد پشتیبانی شایگان سیستم تماس بگیرید یا از طریق `تیکت` در `پورتال مشتریان` پیام ارسال کنید.
