# پارامترهای پروژه در نرم‌افزار حسابگر

## مقدمه

برای مدیریت دقیق‌تر پروژه‌ها در نرم‌افزار `حسابگر`، پارامترهایی تعریف شده است که با استفاده از آنها می‌توانید نحوه عملکرد بخش پروژه را مطابق با نیاز مجموعه خود تنظیم کنید.

---

## مسیر دسترسی

برای تعیین تنظیمات مربوط به پروژه:

- از مسیر `اطلاعات پایه` -> `پروژه` -> `پارامترهای پروژه` را انتخاب کنید.

---

## پارامترهای پروژه

|                                         پارامتر |                                                        توضیح |
| ----------------------------------------------: | -----------------------------------------------------------: |
|       `در اسناد فقط آخرین سطح قابل انتخاب باشد` | در هنگام صدور اسناد، فقط می‌توانید `آخرین سطح پروژه` را انتخاب کنید |
| `قبل از صدور سند برای پروژه تاریخ پروژه چک شود` | چنانچه `تاریخ سند` از `تاریخ انقضای پروژه` بزرگتر باشد، سیستم `امکان صدور سند` را نمی‌دهد |

---

## نکات مهم

|               نکته |                                                        توضیح |
| -----------------: | -----------------------------------------------------------: |
|           `۱۰ سطح` |                    امکان تعریف پروژه‌ها تا `۱۰ سطح` وجود دارد |
|      `نمودار سطحی` |              تعریف پروژه‌ها از طریق `نمودار سطحی` انجام می‌شود |
|            `فرزند` |        برای تعریف زیرمجموعه‌ها، از گزینه `فرزند` استفاده کنید |
| `اختصاص به فاکتور` |          پروژه را می‌توان به فاکتورهای فروش و خرید اختصاص داد |
|    `اختصاص به سند` |                    در ردیف‌های سند نیز می‌توان پروژه تعیین کرد |
|     `اختصاص به چک` |                         امکان اختصاص پروژه به چک‌ها وجود دارد |
|   `گزارشات تفکیکی` |        امکان تهیه گزارشات تفکیک‌شده بر اساس پروژه‌ها در هر سطح |
|        `پارامترها` | تنظیمات مربوط به پروژه از طریق `پارامترهای پروژه` قابل مدیریت است |

---

## خلاصه گام‌ها

### تنظیم پارامترهای پروژه

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ |           مسیر `اطلاعات پایه` → `پروژه` → `پارامترهای پروژه` |
|     ۲ | پارامتر `در اسناد فقط آخرین سطح قابل انتخاب باشد` را فعال/غیرفعال کنید |
|     ۳ | پارامتر `قبل از صدور سند برای پروژه تاریخ پروژه چک شود` را فعال/غیرفعال کنید |
|     ۴ |                                        تغییرات را ذخیره کنید |

---

### مدیریت پروژه

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ |                منوی `اطلاعات پایه` → `پروژه` → `معرفی پروژه` |
|     ۲ |     در `نمودار سطحی`، کلیک راست کرده و `جدید` را انتخاب کنید |
|     ۳ |                                   اطلاعات پروژه را وارد کنید |
|     ۴ | برای تعریف زیرمجموعه، روی پروژه کلیک راست کرده و `فرزند` را انتخاب کنید |
|     ۵ | در فاکتور، سند، چک یا برگه دریافت/پرداخت، پروژه را اختصاص دهید |
|     ۶ | از مسیر `اطلاعات پایه` → `پروژه` → `وضعیت گردش پروژه`، وضعیت را مشاهده کنید |
|     ۷ | از مسیر `گزارشات` → `گزارشات مراکز هزینه و پروژه`، گزارشات را تهیه کنید |

---

## جمع‌بندی

- `پارامترهای پروژه` امکان کنترل دقیق‌تر بر نحوه استفاده از پروژه‌ها در اسناد را فراهم می‌کنند.
- پارامتر `در اسناد فقط آخرین سطح قابل انتخاب باشد`، انتخاب سطوح میانی را محدود می‌کند.
- پارامتر `قبل از صدور سند برای پروژه تاریخ پروژه چک شود`، از صدور سند با تاریخ دیرتر از تاریخ انقضای پروژه جلوگیری می‌کند.
- تنظیمات پروژه در `اطلاعات پایه` → `پروژه` → `پارامترهای پروژه` قابل مدیریت است.
