# وضعیت گردش پروژه در نرم‌افزار حسابگر

## مقدمه

در نرم‌افزار `حسابگر`، با استفاده از بخش `وضعیت گردش پروژه`، می‌توانید وضعیت مالی و تراکنش‌های مربوط به هر پروژه را به‌صورت تفکیک‌شده مشاهده کنید. این قابلیت به شما امکان می‌دهد تا عملکرد هر پروژه را در سطوح مختلف بررسی کنید.

---

## مسیر دسترسی

برای مشاهده وضعیت گردش پروژه‌ها:

- از مسیر `اطلاعات پایه` -> `پروژه` -> `وضعیت گردش پروژه` را انتخاب کنید.

---

## تنظیمات و فیلترهای گزارش

در فرم باز شده، در قسمت `فیلترها`، می‌توانید با استفاده از فیلترهای زیر، گزارش را محدود کنید:

|          فیلتر |                            توضیح |
| -------------: | -------------------------------: |
|        `تاریخ` | محدوده زمانی مورد نظر برای گزارش |
|       `حساب‌ها` |    انتخاب حساب‌های خاص برای نمایش |
| `تفصیلی شناور` |       فیلتر بر اساس تفصیلی شناور |
|        `و ...` |              سایر فیلترهای موجود |

---

## مشاهده وضعیت گردش پروژه

در قسمت `پروژه‌ها`، می‌توانید:

- `پروژه مورد نظر` خود را در **هر سطح** انتخاب کنید.
- `وضعیت گردش` هر سطح آن را به‌صورت **تفکیک‌شده** مشاهده کنید.

---

## نکات مهم

|             نکته |                                               توضیح |
| ---------------: | --------------------------------------------------: |
|     `سطوح پروژه` |          امکان مشاهده وضعیت گردش در هر سطح از پروژه |
| `فیلترهای متنوع` | استفاده از فیلترهای تاریخ، حساب، تفصیلی شناور و ... |
|   `گزارش تفکیکی` |                   نمایش تفکیک‌شده تراکنش‌های هر پروژه |
|   `مدیریت پروژه` |             امکان بررسی عملکرد هر پروژه به‌صورت مجزا |

---

## خلاصه گام‌ها

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ |           مسیر `اطلاعات پایه` → `پروژه` → `وضعیت گردش پروژه` |
|     ۲ | در قسمت `فیلترها`، محدوده مورد نظر را تنظیم کنید (`تاریخ`، `حساب‌ها`، `تفصیلی شناور` و ...) |
|     ۳ | در قسمت `پروژه‌ها`، پروژه مورد نظر را در سطح دلخواه انتخاب کنید |
|     ۴ |             وضعیت گردش هر سطح را به‌صورت تفکیک‌شده مشاهده کنید |

---

## جمع‌بندی

- `وضعیت گردش پروژه` یکی از امکانات مدیریتی نرم‌افزار حسابگر برای بررسی عملکرد پروژه‌ها است.
- با استفاده از `فیلترها`، می‌توانید گزارش را بر اساس نیاز خود محدود کنید.
- امکان مشاهده `وضعیت گردش` در **هر سطح** از پروژه وجود دارد.
- این گزارش به شما کمک می‌کند تا تراکنش‌های مالی هر پروژه را به‌صورت تفکیک‌شده بررسی کنید.
