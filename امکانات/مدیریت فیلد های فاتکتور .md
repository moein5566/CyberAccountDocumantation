# مدیریت فیلدهای فاکتور در نرم‌افزار حسابگر

## مقدمه

در نرم‌افزار `حسابگر`، می‌توانید مشخص کنید که `چه فیلدهایی` در فاکتور نمایش داده شوند. این قابلیت به شما امکان می‌دهد تا فرم فاکتور را بر اساس نیاز خود شخصی‌سازی کنید و فقط فیلدهای مورد نظر را نمایش دهید.

---

## مسیر دسترسی

- از مسیر `شرایط محیطی` -> `پارامترهای خرید و فروش` بروید.
- روی دکمه مربوط به `پارامتر شماره ۲۵` (`مدیریت فیلدهای فاکتور`) کلیک کنید.

---

## نحوه مدیریت فیلدها

در پنجره باز شده، دو لیست مشاهده می‌شود:

|            لیست |                                                   توضیح |
| --------------: | ------------------------------------------------------: |
|   `لیست سمت چپ` | فیلدهایی که **در حال حاضر** در فاکتور نمایش داده می‌شوند |
| `لیست سمت راست` |         فیلدهایی که **قابلیت نمایش** در فاکتور را دارند |

---

### اضافه کردن فیلد به فاکتور
1. از جعبه لیست سمت راست، آیتم مورد نظر خود را انتخاب کنید.
2. روی دکمه `اضافه` کلیک کنید.
3. فیلد مربوطه به فاکتور اضافه می‌شود.

---

### تنظیم ترتیب نمایش فیلدها
- برای تنظیم محل قرارگیری فیلدها در فاکتور، از دکمه‌های `بالا` و `پایین` استفاده کنید.
- فیلدی که در بالای لیست قرار دارد، در بالای فاکتور نمایش داده می‌شود.

---

## فیلدهای قابل مدیریت در فاکتور

برخی از فیلدهایی که می‌توانید نمایش آنها را در فاکتور مدیریت کنید، عبارتند از:

|                                   فیلد |                           توضیح |
| -------------------------------------: | ------------------------------: |
|                          `اطلاعات فنی` |       اطلاعات فنی مربوط به کالا |
|                          `محل نگهداری` |       محل نگهداری کالا در انبار |
|                                 `واحد` |            واحد شمارش اصلی کالا |
|                               `واحد ۲` |             واحد شمارش دوم کالا |
|                                 `فی ۲` |      قیمت واحد بر اساس واحد دوم |
|                           `توضیح ردیف` | توضیحات مربوط به هر ردیف فاکتور |
| `شناسه یکتای ثبت قرارداد حق‌العمل کاری` |      شناسه قرارداد حق‌العمل کاری |
|                                `پروژه` |      پروژه مرتبط با ردیف فاکتور |
|                         `فی قبل تخفیف` |    قیمت واحد قبل از اعمال تخفیف |
|                       `مبلغ قبل تخفیف` | مبلغ کل ردیف قبل از اعمال تخفیف |
|                           `مشخصه کالا` |          مشخصات و ویژگی‌های کالا |

---

## نکات مهم

|               نکته |                                                توضیح |
| -----------------: | ---------------------------------------------------: |
|         `شخصی‌سازی` |          امکان نمایش فقط فیلدهای مورد نیاز در فاکتور |
|      `ترتیب نمایش` |  تنظیم ترتیب قرارگیری فیلدها با دکمه‌های بالا و پایین |
|      `افزودن فیلد` |             اضافه کردن فیلدهای جدید از لیست سمت راست |
| `پارامتر شماره ۲۵` | این تنظیمات از طریق پارامتر شماره ۲۵ قابل دسترسی است |
|    `فیلدهای متنوع` |        امکان مدیریت فیلدهای اطلاعاتی، قیمتی و تکمیلی |

---

## خلاصه گام‌ها

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ |               مسیر `شرایط محیطی` -> `پارامترهای خرید و فروش` |
|     ۲ | روی دکمه مربوط به `پارامتر شماره ۲۵` (`مدیریت فیلدهای فاکتور`) کلیک کنید |
|     ۳ |               از لیست سمت راست، فیلد مورد نظر را انتخاب کنید |
|     ۴ |                                   روی دکمه `اضافه` کلیک کنید |
|     ۵ | در صورت نیاز، با دکمه‌های `بالا` و `پایین` ترتیب را تنظیم کنید |
|     ۶ |                                        تغییرات را ذخیره کنید |

---

## جمع‌بندی

- `مدیریت فیلدهای فاکتور` به شما امکان می‌دهد تا فرم فاکتور را شخصی‌سازی کنید.
- می‌توانید فیلدهای جدید اضافه کرده یا فیلدهای غیرضروری را حذف کنید.
- ترتیب نمایش فیلدها نیز قابل تنظیم است.
- فیلدهای قابل مدیریت شامل `اطلاعات فنی`، `محل نگهداری`، `واحد`، `فی ۲`، `توضیح ردیف`، `پروژه`، `فی قبل تخفیف`، `مبلغ قبل تخفیف`، `مشخصه کالا` و ... هستند.
- این تنظیمات از طریق `پارامتر شماره ۲۵` در `پارامترهای خرید و فروش` قابل دسترسی است.
