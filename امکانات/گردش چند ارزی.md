# گردش چند ارزی در نرم‌افزار حسابگر

## مقدمه

یکی از امکانات نرم‌افزار `حسابگر`، استفاده از قابلیت `چند ارزی` می‌باشد.

با استفاده از این قابلیت، می‌توان `فاکتورها` و `اسناد` را با ارزهایی غیر از ارز پیش‌فرض سیستم ایجاد کرد و بر اساس همان ارزها نیز گزارش‌گیری کرد.

---

## گزارشات چند ارزی

گزارشات چند ارزی از دو مسیر زیر قابل دسترسی هستند:

|                                                         مسیر |                              توضیح |
| -----------------------------------------------------------: | ---------------------------------: |
| `گزارشات` -> `گزارشات عمومی حسابداری` -> `گزارش حساب چند ارزی` |             گزارش اختصاصی چند ارزی |
| `گزارشات` -> `گزارشات عمومی` -> `سطحی مانده حساب‌ها` -> `گزارش دفتر معین حساب‌ها` | گزارش دفتر معین با قابلیت چند ارزی |

---

## مهم‌ترین گزارش چند ارزی

مهم‌ترین گزارش در این بخش، گزارش `دفتر معین حساب‌ها` می‌باشد که با استفاده از آن می‌توان گردش ارزی حساب‌ها را به‌صورت دقیق مشاهده کرد.

---

## مسیر دسترسی به گزارش دفتر معین چند ارزی

### روش اول: از طریق منو
- از مسیر `گزارشات` -> `گزارشات عمومی` -> `سطحی مانده حساب‌ها` -> `گزارش دفتر معین حساب‌ها` را انتخاب کنید.

### روش دوم: از طریق کلید میانبر
- کلید `Shift+1` را بزنید.

---

## مراحل تنظیم و مشاهده گزارش چند ارزی

### مرحله ۱: انتخاب طرف حساب
- پس از باز شدن فرم گزارش، `طرف حساب` مورد نظر را انتخاب کنید.

---

### مرحله ۲: فعال‌سازی و تنظیمات چند ارزی
- گزینه `چند ارزی` را روی `بله` قرار دهید.

|                     تنظیمات |                                                        توضیح |
| --------------------------: | -----------------------------------------------------------: |
| `بر اساس نرخ زمان ورود ارز` | گردش بر اساس نرخی که در آن تاریخ وارد کرده‌اید، نشان داده می‌شود |
|       `بر اساس نرخ روز ارز` |                         گردش بر اساس نرخ روز نشان داده می‌شود |
|          `ردیف‌های چند ارزی` |                   ردیف‌هایی که `بدون ارز` هستند را نشان می‌دهد |
|             `بر حسب یک ارز` |           باید ارز مورد نظر را از قسمت `نوع ارز` انتخاب کنید |
|           `فقط ارز انتخابی` |                           فقط ارز انتخاب‌شده نمایش داده می‌شود |

---

## نکات مهم

|              نکته |                                               توضیح |
| ----------------: | --------------------------------------------------: |
|  `نسخه ۹ به بالا` | قابلیت چند ارزی از `نسخه ۹` به بعد قابل استفاده است |
|   `نرخ زمان ورود` |               گردش بر اساس نرخ ارز در تاریخ ثبت سند |
|         `نرخ روز` |             گردش بر اساس نرخ ارز در تاریخ گزارش‌گیری |
| `گزارش دفتر معین` |           مهم‌ترین گزارش برای تحلیل گردش ارزی حساب‌ها |
|     `کلید میانبر` |       `Shift+1` برای دسترسی سریع به گزارش دفتر معین |

---

## خلاصه گام‌ها

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ | مسیر `گزارشات` -> `گزارشات عمومی` -> `سطحی مانده حساب‌ها` -> `گزارش دفتر معین حساب‌ها` (یا `Shift+1`) |
|     ۲ |                           `طرف حساب` مورد نظر را انتخاب کنید |
|     ۳ |                      گزینه `چند ارزی` را روی `بله` قرار دهید |
|     ۴ | `نوع چند ارزی` را انتخاب کنید (`بر اساس نرخ زمان ورود` یا `بر اساس نرخ روز`) |
|     ۵ | در صورت نیاز، `نوع ارز` را انتخاب کنید (`ردیف‌های چند ارزی`، `بر حسب یک ارز` یا `فقط ارز انتخابی`) |
|     ۶ |                                         گزارش را مشاهده کنید |

---

## جمع‌بندی

- `چند ارزی` یکی از امکانات نسخه ۹ به بالای نرم‌افزار حسابگر است.
- با این قابلیت، می‌توان اسناد و فاکتورها را با ارزهای مختلف ثبت کرد.
- مهم‌ترین گزارش، `گزارش دفتر معین حساب‌ها` است که از طریق `Shift+1` قابل دسترسی است.
- دو نوع نمایش گردش ارزی وجود دارد: `بر اساس نرخ زمان ورود` و `بر اساس نرخ روز`.
