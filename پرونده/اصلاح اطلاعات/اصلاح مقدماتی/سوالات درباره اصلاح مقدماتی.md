# سوالات متداول درباره اصلاح مقدماتی در نرم‌افزار حسابگر

## مقدمه

`اصلاح مقدماتی` یکی از ابزارهای مهم در نرم‌افزار `حسابگر` است که به شما کمک می‌کند تا مشکلات رایج در حساب‌ها، اسناد، فاکتورها و کاردکس کالاها را شناسایی و رفع کنید. در این مقاله به سوالات متداول در این زمینه پاسخ داده شده است.

---

## سوال اول: چطوری سندهای غیر تراز را پیدا کنیم؟

### ❓ سوال
> چطوری سندهای غیر تراز را پیدا کنیم؟

### ✅ پاسخ
برای پیدا کردن سندهای غیر تراز، مراحل زیر را دنبال کنید:

1. از مسیر `پرونده` -> `اصلاح اطلاعات` -> `اصلاح مقدماتی` بروید.
2. به سربرگ `کنترل اسناد حسابداری` بروید.
3. در این بخش، لیست `سندهای خالی` و `غیر تراز` نمایش داده می‌شود.
4. در ستون `نوع خطا`، علت خطای هر ردیف نمایش داده می‌شود.

---

## سوال دوم: چطوری تصحیح کاردکس انجام بدم؟

### ❓ سوال
> چطوری تصحیح کاردکس انجام بدم؟

### ✅ پاسخ
برای تصحیح کاردکس کالاها، مراحل زیر را دنبال کنید:

1. از مسیر `پرونده` -> `اصلاح اطلاعات` -> `اصلاح مقدماتی` بروید.
2. به سربرگ `کنترل اقلام موجودی` بروید.
3. در این بخش، لیست کالاهایی که کاردکس آنها دارای اشکال است نمایش داده می‌شود.
4. با استفاده از دکمه‌های موجود، کاردکس را تصحیح کنید:
   - `تصحیح کاردکس`: برای محاسبه مجدد کاردکس
   - `تصحیح تاریخ کاردکس`: برای رفع مشکلات تاریخی
   - `تصحیح فی در رسید انبار تولید`: برای رفع مغایرت فی در رسید تولید
   - `تصحیح فی در رسید انبار انتقال`: برای رفع مغایرت فی در رسید انتقال

---

## سوال سوم: اختلاف مانده در گزارش و لیست

### ❓ سوال
> گزارش `Shift+1` می‌گیرم، چیزی که نشان می‌دهد با مانده‌ای که در لیست هست فرق دارد. چیکار باید بکنم؟

### ✅ پاسخ
این مشکل معمولاً به دلیل `بروز نبودن مانده حساب‌ها` رخ می‌دهد. برای رفع آن:

1. از مسیر `پرونده` -> `اصلاح اطلاعات` -> `اصلاح مقدماتی` بروید.
2. به سربرگ `کنترل حساب‌ها` بروید.
3. روی دکمه `تصحیح تمامی حساب‌ها` کلیک کنید.
4. پس از اتمام عملیات، مجدداً گزارش بگیرید.

---

## سوال چهارم: چجوری سند همه فاکتورها رو صادر کنم؟

### ❓ سوال
> چجوری سند همه فاکتورها رو صادر کنم؟

### ✅ پاسخ
برای صدور سند برای کلیه فاکتورها:

1. از مسیر `پرونده` -> `اصلاح اطلاعات` -> `اصلاح مقدماتی` بروید.
2. به سربرگ `کنترل فاکتورها` بروید.
3. روی دکمه `صدور سند کلیه فاکتورها` کلیک کنید.
4. سیستم برای تمام فاکتورهایی که سند ندارند، سند حسابداری صادر می‌کند.

---

## سوال پنجم: چجوری موجودی کالاهایی که منفی شدن را پیدا کنم؟

### ❓ سوال
> چجوری موجودی کالاهایی که منفی شدن را پیدا کنم؟

### ✅ پاسخ
برای پیدا کردن کالاهای با موجودی منفی:

1. از مسیر `پرونده` -> `اصلاح اطلاعات` -> `اصلاح مقدماتی` بروید.
2. به سربرگ `کنترل اقلام موجودی` بروید.
3. در این بخش، لیست کالاهایی با `موجودی یا فی منفی` نمایش داده می‌شود.
4. در ستون `نوع خطا`، علت خطا مشخص شده است.
5. برای اصلاح موجودی منفی، از طریق صدور `فاکتور تعدیل` اقدام کنید.

---

## سوال ششم: مانده حساب واسط بین انبار صفر نیست

### ❓ سوال
> مانده حساب واسط بین انبار باید همیشه صفر باشد، اما الان نیست. چرا؟

### ✅ پاسخ
این مشکل معمولاً به دلیل `تغییر قیمت میانگین` یکی از کالاها رخ می‌دهد.

### 🔧 راهکار
برای رفع این مشکل:

1. از مسیر `پرونده` -> `اصلاح اطلاعات` -> `اصلاح مقدماتی` بروید.
2. به سربرگ `کنترل اقلام موجودی` بروید.
3. روی دکمه `تصحیح فی در رسید انبار انتقال` کلیک کنید.
4. این کار مغایرت فی کالاها را در رسید و حواله انتقال تصحیح می‌کند و مانده حساب واسط را به حالت صحیح بازمی‌گرداند.

## نکات مهم

|                                     توضیح |                            نکته |
| ----------------------------------------: | ------------------------------: |
|     برای پیدا کردن سندهای غیر تراز و خالی |          `کنترل اسناد حسابداری` |
| برای بررسی و تصحیح کاردکس و موجودی کالاها |            `کنترل اقلام موجودی` |
|               برای بروزرسانی مانده حساب‌ها |                  `کنترل حساب‌ها` |
|       برای صدور سند فاکتورها و رفع مشکلات |                `کنترل فاکتورها` |
|   برای رفع مشکل مانده حساب واسط بین انبار | `تصحیح فی در رسید انبار انتقال` |

| مرحله |                                                        اقدام |
| :---- | -----------------------------------------------------------: |
| ۱     |          مسیر `پرونده` -> `اصلاح اطلاعات` -> `اصلاح مقدماتی` |

| ۳     |                                         مشکل را شناسایی کنید |
| ۴     |                 از دکمه‌های مربوطه برای رفع مشکل استفاده کنید |

## جمع‌بندی

- `اصلاح مقدماتی` یکی از ابزارهای کلیدی برای شناسایی و رفع مشکلات در نرم‌افزار حسابگر است.
- برای پیدا کردن `سندهای غیر تراز`، از سربرگ `کنترل اسناد حسابداری` استفاده کنید.
- برای `تصحیح کاردکس` و `موجودی منفی`، از سربرگ `کنترل اقلام موجودی` استفاده کنید.
- برای `بروزرسانی مانده حساب‌ها`، از سربرگ `کنترل حساب‌ها` و دکمه `تصحیح تمامی حساب‌ها` استفاده کنید.
- برای `صدور سند کلیه فاکتورها`، از سربرگ `کنترل فاکتورها` استفاده کنید.
- در صورت بروز مشکل در `حساب واسط بین انبار`، از دکمه `تصحیح فی در رسید انبار انتقال` استفاده کنید.
