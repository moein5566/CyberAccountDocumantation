# مرحله ۶: محاسبه کمیسیون در مدیریت پورسانت

## مقدمه

در این مرحله، سیستم به‌صورت خودکار `کمیسیون (پورسانت)` فروشندگان را بر اساس `قوانین کمیسیون` تعریف‌شده و `فاکتورهای فروش` صادرشده محاسبه می‌کند.

---

## مسیر دسترسی

- از مسیر `عملیات روزانه` -> `مدیریت سیاست‌های فروش و تخفیفات` -> `مدیریت پورسانت` -> `محاسبه کمیسیون` را انتخاب کنید.

---

## مراحل محاسبه

### مرحله ۱: مشاهده تاریخچه
- در زبانه `تاریخچه محاسبه`، می‌توانید تاریخچه محاسبات قبلی را مشاهده کنید.

---

### مرحله ۲: شروع محاسبه جدید
- برای محاسبه جدید، روی دکمه `محاسبه جدید` کلیک کنید.

---

### مرحله ۳: تعیین تاریخ
- تاریخ مورد نظر را انتخاب کنید.
- روی دکمه `تایید` کلیک کنید.

---

## انتخاب فروشندگان

- در زبانه `لیست فروشنده‌ها`، فروشندگان مورد نظر برای محاسبه را انتخاب کنید.

---

## نوع محاسبه

|             نوع محاسبه |                                                        توضیح |
| ---------------------: | -----------------------------------------------------------: |
|        `تمام فاکتورها` |       محاسبه بر اساس تمام فاکتورهای `تسویه‌شده` و `تسویه‌نشده` |
| `فاکتورهای پرداخت شده` | محاسبه فقط بر اساس فاکتورهایی که برای آنها `مبلغ دریافت` شده است |

---

## نتایج محاسبات

پس از انجام محاسبه، نتایج در زبانه `نتایج محاسبات` نمایش داده می‌شود:

|                   ستون |                                          توضیح |
| ---------------------: | ---------------------------------------------: |
|             `شرح ردیف` |               شرح تعریف‌شده در `قوانین کمیسیون` |
|                 `دوره` |                       شماره `دوره مالی` فاکتور |
|         `درصد کمیسیون` |                         `مبلغ کمیسیون` فروشنده |
|         `محاسبات قبلی` |              مبالغ محاسبه‌شده در `محاسبات قبلی` |
| `مبنای محاسبه پورسانت` |               `مبلغ کل فاکتورهای فروش` فروشنده |
|    `مبلغ جریمه مرجوعی` |                    `مبلغ جریمه مرجوعی` فروشنده |
|  `محاسبات قبلی مرجوعی` | مبالغ جریمه مرجوعی محاسبه‌شده در `محاسبات قبلی` |
|  `مبنای محاسبه مرجوعی` |             `مبلغ کل فاکتورهای مرجوعی` فروشنده |

---

## نکات مهم

|                 نکته |                                                        توضیح |
| -------------------: | -----------------------------------------------------------: |
|    `محاسبه از ابتدا` |                   محاسبات همیشه از `ابتدای دوره` انجام می‌شود |
| `تغییرات لحاظ می‌شود` | تمامی تغییرات در فاکتور، قوانین و ... در محاسبه جاری لحاظ می‌شود |
|         `نوع محاسبه` |         انتخاب بین `تمام فاکتورها` یا `فاکتورهای پرداخت شده` |
|           `صدور سند` | پس از محاسبه، با انتخاب `صدور سند`، اسناد پورسانت صادر می‌شود |

---

## خلاصه گام‌ها

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ | مسیر `عملیات روزانه` -> `مدیریت سیاست‌های فروش و تخفیفات` -> `مدیریت پورسانت` -> `محاسبه کمیسیون` |
|     ۲ |       در زبانه `تاریخچه محاسبه`، روی `محاسبه جدید` کلیک کنید |
|     ۳ |                 تاریخ مورد نظر را انتخاب کرده و `تایید` کنید |
|     ۴ | در زبانه `لیست فروشنده‌ها`، فروشندگان مورد نظر را انتخاب کنید |
|     ۵ | `نوع محاسبه` را انتخاب کنید (`تمام فاکتورها` یا `فاکتورهای پرداخت شده`) |
|     ۶ |                                  روی دکمه `محاسبه` کلیک کنید |
|     ۷ |                نتایج را در زبانه `نتایج محاسبات` مشاهده کنید |
|     ۸ |                       در صورت نیاز، روی `صدور سند` کلیک کنید |

---

## جمع‌بندی

- `محاسبه کمیسیون` مرحله ششم از فرآیند مدیریت پورسانت است.
- سیستم به‌صورت خودکار پورسانت فروشندگان را محاسبه می‌کند.
- دو نوع محاسبه وجود دارد: `تمام فاکتورها` و `فاکتورهای پرداخت شده`.
- نتایج محاسبه شامل `مبلغ کمیسیون`، `جریمه مرجوعی` و `مبنای محاسبه` است.
- پس از محاسبه، می‌توان `سند پورسانت` را صادر کرد.
