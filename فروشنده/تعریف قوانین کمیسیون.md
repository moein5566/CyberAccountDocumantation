# مرحله ۴: تعریف قوانین کمیسیون در مدیریت پورسانت

## مقدمه

در این مرحله، `قوانین کمیسیون (پورسانت)` را برای فروشندگان تعریف می‌کنیم. این قوانین مشخص می‌کنند که بر اساس چه شرایطی، به هر فروشنده چه میزان پورسانت تعلق می‌گیرد.

---

## مسیر دسترسی

- از مسیر `عملیات روزانه` -> `مدیریت سیاست‌های فروش و تخفیفات` -> `مدیریت پورسانت` -> `قوانین کمیسیون` را انتخاب کنید.

---

## فیلدهای تعریف قانون کمیسیون

|                          فیلد |                                                        توضیح |
| ----------------------------: | -----------------------------------------------------------: |
|                    `شرح ردیف` |                       شرح مربوط به هر ردیف از قوانین کمیسیون |
|                  `بازه تاریخ` |                        محدوده تاریخی فاکتورهای مشمول پورسانت |
|                    `نام حساب` |                   فاکتورهایی که به نام حساب مشخص صادر شده‌اند |
|               `نام حساب معین` |      فاکتورهایی که به نام تفصیلی در آن معین مشخص صادر شده‌اند |
|                 `نام حساب کل` |        فاکتورهایی که به نام تفصیلی در آن کل مشخص صادر شده‌اند |
|                    `شرح کالا` |                   فاکتورهایی که کالای مشخص در آنها وجود دارد |
|               `نام گروه کالا` |              فاکتورهایی که کالای گروه مشخص در آنها وجود دارد |
|          `نام گروه اصلی کالا` |         فاکتورهایی که کالای گروه اصلی مشخص در آنها وجود دارد |
|                         `محل` |           فاکتورهایی که مشتریان آنها مرتبط با محل مشخص هستند |
|            `شماره مرکز هزینه` |   فاکتورهایی که مرکز هزینه آنها با مرکز هزینه مشخص برابر است |
|                       `مسافت` | فاکتورهایی که مسافت تعریف‌شده برای مشتریان آنها برابر عدد مشخص است |
| `از مبلغ فروش و تا مبلغ فروش` |                         محدوده مبلغ فروش برای دریافت پورسانت |
|                `درصد کمیسیون` |                            درصد پورسانت تعلق‌گرفته به فروشنده |
|           `درصد جریمه مرجوعی` |                       درصد جریمه در صورت داشتن فاکتور مرجوعی |

---

## نکات مهم در تعریف قوانین

|            نکته |                                                        توضیح |
| --------------: | -----------------------------------------------------------: |
|      `شرط کامل` | در محاسبه پورسانت، **تمام شرط‌های معرفی‌شده** برای یک فاکتور باید صدق کند |
| `جریمه جداگانه` | برای اعمال جریمه برگشت از فروش، باید `درصد کمیسیون` و `درصد جریمه مرجوعی` در **دو قانون جداگانه** تعریف شوند |

---

## مثال عملی

فرض کنید می‌خواهید برای `گروه فروشنده ۱` قانون کمیسیون تعریف کنید:

|           فیلد |                        مقدار |
| -------------: | ---------------------------: |
|     `شرح ردیف` |          `کمیسیون ویزیتورها` |
|   `بازه تاریخ` | `۱۴۰۵/۰۱/۰۱` تا `۱۴۰۵/۱۲/۲۹` |
|     `نام حساب` |                 `همه حساب‌ها` |
| `درصد کمیسیون` |                         `۵%` |

---

## خلاصه گام‌ها

| مرحله |                                                        اقدام |
| ----: | -----------------------------------------------------------: |
|     ۱ | مسیر `عملیات روزانه` -> `مدیریت سیاست‌های فروش و تخفیفات` -> `مدیریت پورسانت` -> `قوانین کمیسیون` |
|     ۲ |                              فروشنده مورد نظر را انتخاب کنید |
|     ۳ |                                       یک سطر جدید ایجاد کنید |
|     ۴ |                               فیلدهای مورد نظر را تکمیل کنید |
|     ۵ |                                        روی `ذخیره` کلیک کنید |

---

## جمع‌بندی

- `قوانین کمیسیون` مرحله چهارم از فرآیند مدیریت پورسانت است.
- قوانین مشخص می‌کنند که بر اساس چه شرایطی به فروشندگان پورسانت تعلق می‌گیرد.
- `تمام شرط‌های تعریف‌شده` برای یک فاکتور باید صدق کند.
- جریمه مرجوعی باید در `قانون جداگانه` تعریف شود.

---

> **توجه**: در صورت نیاز به راهنمایی بیشتر، با واحد پشتیبانی شایگان سیستم تماس بگیرید یا از طریق `تیکت` در `پورتال مشتریان` پیام ارسال کنید.
